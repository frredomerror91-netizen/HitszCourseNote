# 弗兰克—赫兹实验完成教程

## 一、实验目的与原理

测氩原子第一激发电位，比较两种拒斥电压的电流—加速电压曲线。电子能量达到激发阈值时可非弹性碰撞失能，收集电流出现周期起伏；同类极值间距近似对应激发电位，不能用第一个峰的绝对电压直接代替。

预习要点：原子具有离散能级，吸收/放出能量对应能级差。灯丝电压加热阴极；第一栅压帮助引出电子；第二栅压提供主加速；拒斥电压筛选能抵达收集极的电子。

## 二、实验步骤

### 1. 断电连接并按本管标牌设置

1. 输出回规定最小状态并关电，测试仪VG2K、VG2A、VG1K和灯丝输出分别接管架同名输入；管架微电流输出接仪器微电流输入。不得互换电流与电压线。
2. 信号输出接示波器CH1，同步输出接触发端，按本机选择外触发。高压及玻璃管接线按实验室检查后再上电。
3. 手动模式依次选择各电压功能，共用旋钮只调整当前选中项。按**本管出厂标牌**设置灯丝、VG1K、VG2A，写实际值，不照抄他组工作点。
4. VG2K置0 V，预热10—15分钟，确认工作点与电流不再持续漂移。灯丝不高于出厂参考值0.5 V以上，连续工作不超过2小时；上限不是推荐工作点。

### 2. 固定步进，独立扫两条手动曲线

1. VG2K设定时按指导书移位键14并转旋钮13，选0.1、0.2或0.5 V步进，默认0.1 V；面板不同查本机说明。整轮保持同一步进，表头记电流单位和量程。
2. 从0 V单向升至90 V，每点稳定后记实际加速电压、电流和异常。灯丝、第一栅与拒斥保持不变；漏点标记后另组复测，不能反向补入原扫描。
3. 保存第一组后VG2K回零。仅将VG2A在允许范围内改变0.5 V，记改前、改后及方向；回VG2K从0至90 V再扫一条，其他条件相同。
4. 分别画原始散点与曲线，不用自动波形或软件平滑生成手动漏点。

### 3. 同类极值分别逐差与拟合

1. 在每条曲线上分别识别峰序列和谷序列，按顺序编号，记录电压及定位区间。漏掉一个极值不能把后面的序号直接接上。
2. 设同类极值 $U_1,\ldots,U_N$，跨度p的逐差为 $U_{0,j}=(U_{j+p}-U_j)/p$，按指导书适用的配对求平均，列出中间间距，不混峰谷。
3. 最小二乘拟合 $U_j=a+bj$，自由截距a保留，斜率b为激发电位估计。构造例六峰19.8、31.4、43.2、54.8、66.6、78.2 V，跨度3分别为11.667、11.733、11.667 V，平均11.689 V；自由截距拟合b≈11.691 V。示例非实测。
4. 每拒斥条件分别列峰/谷及两种算法结果，与课程约11.6 V参考比较；电子能量增量为 $\Delta E=eU_0$，U0以V表示时同数值能量为eV。

### 4. 自动观察与报告

1. 先保存手动表，按规程归零后切自动，选VG2K并启/停。该模式默认0.2 V步进，调示波器量程、时基和触发使峰谷稳定，存截图与工作点。
2. 自动模式按指导书仅作现象观察；无可靠电压轴标定时，不把横向时间/格数当VG2K来取极值。
3. 报告附两条手动曲线、极值表、逐差与拟合、自动观察及讨论。收尾VG2K及相关输出降至规定最小，再停输出关机。

## 三、注意事项与问题查询

| 现象或讨论 | 优先检查与回答 |
| --- | --- |
| 无峰谷或持续漂移 | 查接线、功能选项、标牌工作点及预热，勿靠超限加灯丝压追峰 |
| 为何主要测到第一激发电位 | 最低可及激发通道及其碰撞概率支配周期失能；不能解释成原子不存在更高能级 |
| 峰和谷计算有何不同 | 理想同类间距应接近，实际极值宽度、背景与定位误差不同，应分别提取比较 |
| 后续谷电流升高 | 随加速增强，电子能量分布和可到达收集极的电子贡献变化，非所有电子都同时恰好失能；结合实际曲线说明 |
