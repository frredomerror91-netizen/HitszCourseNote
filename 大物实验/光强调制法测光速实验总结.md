# 光强调制法测光速完成教程

## 一、实验目的与原理

在课程虚拟仿真中用强度包络相位测空气光速，再由水替换空气的延迟求水中速度。X-Y中两正弦形成椭圆，同相或反相时为直线。往返光路中，镜移动l使光路改变2l；相邻相反斜率直线相差半周期，故 $c_{\rm air}=4fl$。这里f是强度调制频率，不是红光载波频率。

预习要点：同频、等相位差的两个正弦作X-Y显示形成李萨如图；斜率符号区分同相与反相。测频端采用分频输出，必须依本仿真换算实际f。

## 二、实验步骤

### 1. 校准显示并逐线连接

1. 用示波器校准输出依次检查CH1、CH2，按当前标称频率/幅度调时基、量程和校准位置，确认两通道正常。
2. 按图9-15把参考信号接X对应通道、接收信号接Y对应通道、测频输出接发生器外计频INPUT；X/Y分配按当前型号确认。仿真拖线后确认连线保留，在数据表“连线”模块点“确定状态”。
3. 开测光速仪和测频仪，选外计频，记录显示数值与单位。本仿真 $f=1000f_{\rm out}$；如外测51.6 kHz，实际51.6 MHz，不能直接把51.6代入Hz公式。
4. 在反射镜近端、远端分别调光路方向/高度，使光均能回到接收端。完成后固定透镜及几何，不能边测相位边改光路。

### 2. 只移动反射镜测空气光速

1. 切X-Y。按本仿真界面“方式CH2”并按“X-Y”，以两通道分别控制横纵轴为确认判据。把图形调居中且不削顶。
2. 镜在导轨一端附近，仅此时调相位旋钮把椭圆收成直线。记镜坐标 $x_1$、斜率符号、频率和截图。
3. 保持相位旋钮不动，沿一个方向慢移镜，连续跟踪直线→椭圆→**第一次相反斜率直线**，记 $x_2$ 并截图。不能跳过中间一周期后仍按半周期算。
4. 求 $l=|x_2-x_1|$、$c_{\rm air}=4fl$。构造例：0.0520到1.5044 m，l=1.4524 m，f=51.6×10⁶ Hz，得2.9977536×10⁸ m/s。示例不是平台实测。
5. 按模板记录规定组数、频率、两端坐标及斜率证据，比较参考光速；不把坐标差当总光路差。误差先追溯直线判读、坐标读数和频率倍率。

### 3. 先确认水程，再作同相位补偿

1. 核对模板约1 m水管的**实际有效水长** $L_w$、穿水次数q、端窗是否一并撤去，定义累计水程 $L_{\rm eff}=qL_w$。外管长不一定等于水长，单双程不能由镜子往返结构直接猜。
2. 水管放在指导位置，保持接收清楚。允许为此组重设一次相位成直线，记在位坐标 $x_w$、斜率及截图。
3. 撤去水管后保持频率、相位和其余器件，只移镜增加空气路程，使其恢复**相同斜率、同一连续分支**的直线，记 $x_a$。先按导轨正方向检查补偿方向，再取位移大小s。
4. 在端窗效应可忽略或抵消时：

$$
(n-1)L_{\rm eff}=2s,\qquad n=1+\frac{2s}{L_{\rm eff}},\qquad
v_w=\frac{c_{\rm air}}n.
$$

5. 构造例：已独立确认Lw=1.0000 m且双程，Leff=2.0000 m，补偿s=0.3330 m，得n=1.3330。若仅单程，同一s将给1.6660，说明穿越次数是必需条件。
6. 整管连窗撤去时，设累计玻璃厚度tΣ、折射率ng，则应从2s扣除 $(n_g-1)t_\Sigma$ 后再除以Leff。玻璃参数或穿越次数不明时，只保留条件式和原数，待查仿真侧视图/模块说明，不直接报告水中光速。

### 4. 按模板整理并保存

1. 附两类相位截图、外测/实际频率、空气端点、水管几何和补偿坐标，写清窗口处理、公式和结果；原始记录与构造例分开。
2. 课程讨论：本实验测约MHz包络，相位随米量级路程变化；固定两镜间距在两次差分中抵消；忽略一并撤去的玻璃通常使n偏大、水中速度偏小，若两窗各2 mm、玻璃折射率1.5，且每窗穿q次、有效水长1 m，则额外光程为q×0.002 m，忽略窗导致n绝对偏大0.002，速度相对偏差约为−0.002/n；前后窗保留抵消时不加此项。
3. 保存数据表及平台实际完成状态，按课程要求提交。仿真界面未确认的结果不能写已提交。

## 三、注意事项与问题查询

| 现象 | 优先检查与修正 |
| --- | --- |
| X-Y不成稳定椭圆 | 查两输入是否同频、通道分配、耦合和触发/量程，再查接收光 |
| 光速差1000倍或2倍 | 先查分频倍率及kHz/MHz/Hz，再查反斜率、同斜率和往返因子 |
| 撤管后补偿方向反常 | 查坐标定义、是否跨周期或动过相位，不只取绝对值掩盖问题 |
