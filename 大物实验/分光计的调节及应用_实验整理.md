# 分光计的调节及应用完成教程

## 一、实验目的与原理

调好分光计，测汞灯三条谱线的波长、双黄线角色散率和三棱镜对绿光的折射率。正入射光栅满足 $d\sin\theta=k\lambda$；最小偏向角法满足 $n=\sin[(A+\delta_{\min})/2]/\sin(A/2)$，其中 $d$ 为栅距、$k$ 为级次，$A$ 为棱镜顶角。

预习要点：本机主盘每格30′，30个游标间隔对应29个主盘间隔，游标一格实际为29′，主盘与游标格差才是最小读数1′。同侧同级中577.0 nm黄光1比579.1 nm黄光2更靠近绿光。

## 二、实验步骤

### 1. 找到调节部件并完成自准直

1. 准备汞灯、双面镜、300条/mm光栅和棱镜。对照指导书附录1.1：望远镜调焦9、俯仰12，载物台调平7，平行光管调焦2、高低27、缝宽28；编号仅适用于图示型号。
2. 先转目镜使叉丝清楚，再开绿色自准直照明。双面镜一面朝望远镜，调物镜使返回绿十字清楚；轻移眼睛，绿十字与叉丝应无相对滑动。之后固定望远镜焦距。
3. 按图1-15至1-20放镜，翻转载物台180°观察另一面。反射像偏离上基准线时，用望远镜俯仰消除**像偏差的一半**，再用当前靠近望远镜的台面螺钉消除其余偏差。反复翻面，直到两面都对齐；“各半”不是各拧半圈。
4. 移去双面镜，望远镜直对平行光管。只调平行光管焦距使狭缝清晰；狭缝暂转水平，调高低使其与中央水平线重合，再转回竖直。收窄到双黄线可分别瞄准且亮度足够。

### 2. 调光栅并记录九组谱线

1. 按图1-23使光栅面沿载物台刻线C。望远镜仍对准直射像，转载物台找光栅反射十字，只调A或B使其与上交叉点重合，建立正入射；不再动望远镜俯仰。
2. 左右找同级谱线，只调C使两侧等高，再核对中央像。锁紧后检查目标未偏移。
3. 分别测绿光、黄光1、黄光2的正负一、二、三级。每条谱线中心对竖叉丝，每个位置读两个游标，共九组、每组四个原读数。记录度、分、颜色、级次及缺测原因。
4. 读数先取游标零线前主尺，再加重合线分钟数。例如22°30′加9′为22°39′，不能写成22.39°。跨0°按实际小转角展开。

### 3. 计算波长与角色散率

1. 同一游标左右相减得到转角 $\beta_1,\beta_2$，先处理跨零，再算：

$$
\theta_k=\frac{\beta_1+\beta_2}{4},\qquad
\lambda_k=\frac{d\sin\theta_k}{k},\qquad d=\frac{10^6}{300}\,\mathrm{nm}.
$$

2. 构造算例：若两游标转角均为20°，则衍射角10°；一级波长为3333.33×sin10°≈578.83 nm。各颜色分别平均三级结果，与546.1、577.0、579.1 nm比较，计算绝对相对误差。
3. 双黄线各级计算 $D_k=k/(d\cos\theta_k)$。$d$ 用nm时，结果为rad/nm。

### 4. 换棱镜测顶角与最小偏向角

1. 按图1-28放棱镜，磨砂BC面不用作透光面。交替观察AB、AC的自准直返回像，只调台面螺钉，使两像水平线都对上基准线。
2. **固定望远镜和刻度盘，转载物台**，分别使AB、AC返回十字竖线对准竖基准线，各记两游标。两游标各自求方向差并平均得 $\Phi$，顶角为 $A=180^\circ-\Phi$。
3. 使汞光由AB入、AC出，找到绿线。缓慢转载物台改变入射角，同时转望远镜跟踪；找到谱线向顶角方向移动后开始反向的转折点，固定台面，瞄准绿线记两游标。
4. 取下棱镜，望远镜对直射狭缝再记两游标。各游标方向差平均为 $\delta_{\min}$，代入开头公式。构造例：$A=60^\circ$、$\delta_{\min}=40^\circ$，得 $n=\sin50^\circ/\sin30^\circ\approx1.532$。
5. 按模板附九组光栅原数及计算、棱镜两类原数及折射率。白光衍射和黄光折射率为选做。收纳光学件，按规程关灯。

## 三、注意事项与问题查询

| 现象或问题 | 优先检查与处理 |
| --- | --- |
| 翻面后总有偏差 | 单面重合可能由两种倾斜互相补偿；两面各半法才能同时约束望远镜和镜面，检查镜座是否滑动 |
| 看见折射光却没有转折 | 确认光路为指定AB入、AC出，扩大允许的入射角搜索并同步跟踪，避免把反射像或离开视场当转折 |
| 双黄线分不开 | 先查缝宽、焦距和亮度，再辨颜色；不靠改谱线编号凑参考值 |

粗转前松制动，锁紧后用微调；只拿光学件边缘，汞灯不频繁启停。依据：本目录实验一指导书，调节见图1-15至1-25，测量见图1-26至1-32及报告模板。
