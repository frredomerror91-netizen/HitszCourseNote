# 自组光栅光谱仪完成教程

## 一、实验目的与原理

搭建Czerny–Turner光谱仪，经合焦、汞线标定取得可追溯光谱。主要光路为**狭缝→折转平面镜→准直球面镜→反射光栅→聚焦球面镜→CCD**；预习画图时标入射、出射及各器件作用。实物为300线/mm光栅、150 mm焦距双球面镜、3648×8 μm CCD、60 mm双凸透镜；选做Zemax表中100 mm透镜属另一配置，不能混用。

预习要求的闪耀光栅公式可写为“单槽包络×多槽干涉”。设N槽、槽距d、槽面有效宽b。按同一正向以A、B表示从平均面法线指向光源、观察方向的带符号角；以αf、βf表示相应槽面法线下的角。令 $\beta=\pi d(\sin A+\sin B)/\lambda$、$\alpha=\pi b(\sin\alpha_f+\sin\beta_f)/\lambda$。单槽积分振幅正比于 $\int_{-b/2}^{b/2}e^{2i\alpha s/b}\,ds=b\sin\alpha/\alpha$；N槽振幅相加为等比级数，模平方给：

$$
I=I_1\left(\frac{\sin\alpha}{\alpha}\right)^2
\left(\frac{\sin N\beta}{\sin\beta}\right)^2.
$$

I1包含单槽尺度因子；角度正负必须回查本章闪耀槽形图，换角度约定时应同步改光程差。主极大满足 $d(\sin A+\sin B)=m\lambda$，闪耀使包络峰靠近选定级次。

## 二、实验步骤

### 1. 装箱体并建立共同高度

1. 平台横放，装立柱和前挡板，挡光条向内下方，底边贴合；侧后板暂缓安装，USB走专孔，不夹在板下。
2. 按本机规程开校准激光，利用允许调节的外部微透镜使约2 m内光斑尺寸变化不明显。用近、远白屏调高度和方向，两处光斑均对参考中心；禁止直视激光和反射束。
3. 前板装狭缝，先适当开宽，光从中心通过，衍射图左右对称。高度环把各元件中心调到激光高度；激光与狭缝间装扩束镜，四维微调使光对称照缝，再逐渐减缝。

### 2. 用白屏逐段接通折叠光路

1. 狭缝后约40 mm放平面镜，在预计准直镜处放白屏，调镜位置及二维旋钮使入射、反射居中，固定。
2. 准直球面镜替换白屏，入射居中，先使反射聚回狭缝检查共轭；再在光栅位置放白屏，调准直镜底座和角度把光送入屏中心，同时保持镜面入射居中。
3. 光栅替换白屏，入射位于刻线有效区。在预计聚焦镜处放白屏，调光栅让所选最亮一级光斑居中，先查上下对称再固定。
4. 聚焦球面镜替换白屏，尽量减小离轴角且不被支架挡住；微调光栅左右方向使一级光入聚焦镜，在CCD位置放白屏，调聚焦镜把出射送到屏中心。固定后拍整体布局。

### 3. 换连续灯粗调，再采汞灯像素谱

1. 关移校准激光及扩束器，换溴钨灯预热至少15分钟。灯前加光阑，用实物60 mm透镜将灯像对称照狭缝。缝先约0.5—1 mm，用白纸查看分色，调最亮一级进入聚焦镜。
2. 缩小光阑和狭缝，辨认绿光附近成像；CCD放光栅旁，预留大于约10 mm的调角空间，平移轴尽量指向聚焦镜。位置参考图14-24，不照搬仿真坐标。
3. 依规程关溴钨灯、换汞灯，预热至少15分钟。调灯像照缝，装避光板，USB接电脑，开软件选实际设备/COM口，连续测量。
4. 先看原始像素谱，调曝光、缝宽及接收位置，使主要峰可辨且不削顶。指导书建议最高峰约40000—60000，仍以本机量程为准；保存像素—强度原数、曝光和背景设置。

### 4. 平移、转角依次合焦

1. 固定CCD角度、狭缝和采集条件，逐点平移，每点记录435.84与546.07 nm对应峰的像素位置、FWHM和曝光。调焦先用pixel比较，不能套移动前的波长标定。
2. 先选绿峰较窄处，固定平移扫CCD转角，兼顾蓝绿两峰均窄且无截光。小范围联调复查，记录最终位置、转角、缝宽和选择依据。
3. FWHM指半高全宽：局部背景y0、峰顶yp，半高为 $y_0+(y_p-y_0)/2$，取左右交点间距。构造例背景5000、峰顶45000，半高25000，交点1197.333与1202.833 pixel，宽5.500 pixel；不能再除2。
4. 选做狭缝扫描：固定CCD，从小到大单向增缝，记录原刻度、绿峰宽和曝光，作宽度曲线。测微计机械零位不自动等于实际闭合零。最终状态固定后再标定。

### 5. 汞线标定并核对性能

1. 保存最终原始谱，按模板登记365.48、404.66、435.84、546.07、576.96、579.07 nm六条参考线的实际峰位与像素宽度。365.48 nm身份及是否可用须查课程校准表；未检出写缺测，不造像素值。
2. 新模板两列FWHM均标pixel，第二列用途先请教师确认。分析可另列pixel与nm，不能静默改称模板原单位。
3. 按软件/教师模型拟合 $\lambda=f(p)$，记录参考点、模型阶次、系数与残差。宽度换算 $w_\lambda\approx|f'(p)|w_p$，或把两半高交点分别映射再相减。
4. 构造例线性标定斜率0.1000 nm/pixel，则5.500 pixel对应0.5500 nm。按本机手册写入系数，重新读回并采汞谱核对；现有资料未给完整写入菜单，不猜按钮和系数顺序。
5. 检查400—700 nm设计范围的直接覆盖证据、各线宽及双黄线分开情况。分开相距2.11 nm双线不能单独证明0.5 nm分辨率；标定残差与谱线宽分开报告，未被参考线覆盖区注明外推。
6. 按模板交实际搭建照片、原始谱/数据、标定过程和标定后汞谱，附合焦依据。Zemax、狭缝扫描和手机光谱为选做，未做不写完成。按规程关灯电源，热件冷却后收纳。

## 三、注意事项与问题查询

| 现象或讨论 | 优先检查与回答 |
| --- | --- |
| CCD无谱 | 查USB/设备口、连续采集、曝光和逐段通光，再查缝像是否落在探测线 |
| 峰削顶或宽度突跳 | 降曝光，查峰身份、基线及截光，恢复可辨峰后重新读宽 |
| 怎样提高分辨率 | 先优化合焦、像面角度及可用缝宽，控制像差和采样；继续关缝会损失信号，不保证无限变窄 |
| 光谱仪用途 | 波长与谱线识别、光源谱测量、材料光谱分析；应用结论需匹配本机量程及校准能力 |

依据：本目录实验十四指导书槽形与衍射模型、图14-24、实物安装和合焦/标定操作，必交和选做以2026秋模板为准。
