# 巨磁阻效应与应用完成教程

## 一、实验目的与原理

完成模拟转换、等效磁阻、数字开关、电流、角位移、磁卡读写六项实验。巨磁阻器件电阻随磁场变化，桥路把电阻变化转为电压；比较电路形成开关电平。课程螺线管标称匝密度24000 m⁻¹，按 $B=\mu_0nI_M$ 换算，$\mu_0=4\pi\times10^{-7}$ H/m；1 mA约对应0.30159 G，现场先核对线圈标签。

预习要点：磁电阻效应指磁场引起电阻变化；GMR主要取决于多磁层相对磁化取向及自旋相关散射，平行时通常低阻、反平行时高阻；AMR主要取决于单一铁磁材料磁化方向与电流夹角。电流、角位移和磁卡均须先把被测量转为传感器处磁场变化。

## 二、实验步骤

### 1. 区分供电、励磁和信号端

1. 恒流归零，断开相关输出和供电后接线。4 V接组件“巨磁电阻供电”，恒流接“螺线管电流输入”，模拟或开关输出接电压表；需比较电路的项目另接同名“电路供电”。电流表只能串入指定支路。
2. 记录组件朝向，移开无关磁性物品。基本组件传感器位置固定；跨零换励磁方向时先归零、关闭输出，再按本机方法换向。
3. 区分励磁电流 $I_M$、传感器供电支路电流 $I_R$ 和电流组件待测电流 $I_C$，三者不能互代。

### 2. 测模拟转换与等效磁阻

1. 选传感器测量，模拟输出接电压表。按模板从+100 mA逐点到−100 mA，再原路返回；通常10 mA步进，零附近保留±5 mA点。每点记实际励磁电流、方向、输出电压和量程；零场非零输出保留原值。
2. 磁场按实际电流换算。构造例：49.8 mA=0.0498 A，得 $B=1.502\times10^{-3}$ T=15.02 G，不能直接按目标50 mA算。
3. 归零断开输出及相关供电，切“巨磁阻测量”。按图5-12把电流表串入4 V供电与基本组件之间，励磁接法不变，重复完整往返扫描，记录 $I_R$。
4. 图示磁阻档敏感桥臂并联，端口等效电阻 $R_{\rm eq}=U/I_R$。构造例4.00 V/1.600 mA=2500 Ω；仅另确认两臂相等时，单臂电阻才为5000 Ω。绘图写清等效量，不把励磁电流用作分母。

### 3. 记录开关四个翻转阈值

1. 归零断电，恢复传感器档，接4 V和电路供电，将“开关信号输出”接电压表。先确认高低两种稳态及实际电压。
2. 从+50 mA减到−50 mA，分别记录正场高→低的释放、负场低→高的动作；再反向扫回，记负场释放和正场动作。跨零执行安全换向。
3. 每次翻转记带符号电流、换算磁场、方向及前后电平。翻转附近细调并保留阈值所在区间；图中约12 G、10 G只是示意，不填作实测。

### 4. 两种偏置下测电流标定

1. 归零断开后换电流组件，4 V接传感器供电，恒流接“待测电流输入”，信号输出接电压表。
2. 待测电流为零，偏置磁铁置较远侧并调距，使输出约25 mV，记实际零点和位置后固定。再在零待测电流时将磁铁转向接近传感器侧，调距至约150 mV建立适当偏置，记实际零点与位置后固定，不能把25 mV直接当已知磁场。
3. 每种偏置分别从+300、+200、+100、0、−100、−200到−300 mA，再返回，最终四条曲线。组内不移动磁铁，换向仍先归零关输出。
4. 作输出—待测电流图，在线性可用段拟合 $V=aI_C+b$，灵敏度为a；反演 $I_C=(V-b)/a$ 只用于该偏置和标定区间。

### 5. 测角位移与磁卡

1. 断开相关输出后，4 V接角位移组件，输出接电压表，保持磁体、传感器和齿轮间隙。逆时针找同向经过的近零点，记录实际起点角；每3°读一次至48°，共17点。越过目标须重新同向接近，勿反拧消回差。
2. 作输出—相对角图，用同相位峰或零点间距求周期；单个电压可能对应多个角度，不能不说明区间就反演绝对角。
3. 归零关闭后换磁读写组件，4 V、信号输出及其同名电路供电按图5-17和实物核对。指导书将该处目标误称基本组件，缺少引脚图时请教师确认，不猜脚号。
4. 同时按“0/1转换”和“写确认”约2 s初始化。先定中间1—8区域的二进制码及高低位方向；磁卡刻度朝前、按箭头插入。红灯写1、绿灯写0，按住确认，匀速让每区完整经过写头，在区界换位。
5. 松开写确认再读取。各区中心记实际电压、判码与原计划，先用已知0/1确认两种电平，不把写入指示灯当读出结果。保存错误区电压后再复写。
6. 按模板六张表整理各方向曲线、阈值、标定和码表。恒流归零、退出写入，再关供电、收纳磁卡和偏置磁体。

## 三、注意事项与问题查询

| 现象 | 优先检查与修正 |
| --- | --- |
| 模拟输出不变 | 查是否误接开关口、恒流是否真实变化、量程是否溢出；大场平台与全程无响应分开判断 |
| 零场电阻无穷大 | 核对分母是否错用了励磁电流，应使用4 V支路电流 |
| 开关不翻转 | 查电路供电和输出端，再看扫描是否覆盖阈值 |
| 磁卡局部不稳 | 先松确认，在区域内部读，查是否区中途换位；全卡无区分再查初始化和供电 |

磁滞以同场不同扫描支比较；漂移先查零点、温度和外部磁场。课程讨论结合这一区别，以及偏置改变工作段灵敏度回答。依据：本目录实验五指导书图5-11至5-17及六项记录表、2026秋模板。
