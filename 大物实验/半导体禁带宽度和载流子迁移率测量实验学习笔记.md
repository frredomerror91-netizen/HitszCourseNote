# 半导体禁带宽度和载流子参数测量完成教程

## 一、实验目的与原理

测InSb样品不同温度下霍尔电压—工作电流关系，求霍尔系数和载流子参数，在适用本征温区估计禁带宽度。霍尔电压由载流子受横向磁力并建立平衡电场产生，$V_H=R_HI_SB/d$，电流相关灵敏度 $K_H=V_H/(I_SB)=R_H/d$。禁带宽度Eg是导带底与价带顶能量差；载流子包括电子和空穴。

按新模板必须有**至少六个温度，每温11个电流，每电流四向电压**，最低264个横向原读数。温控范围为当天环境温度−20℃至+40℃，不能照搬旧指导书五个示例温度。

## 二、实验步骤

### 1. 关闭控温及输出后接线

本节适用COC-BWHL平台、COC-BWHL-C测试仪、COC-PS电源和COC-HL-Z转接盒。探头按规定放入测试孔，按定位插头连接：

| 起点 | 终点 |
| --- | --- |
| 探头单头四芯 | 转接盒“信号输入” |
| 探头单头六芯 | 测试仪背面“信号采集” |
| 平台控温，双头四芯 | 测试仪背面“控温” |
| 平台风扇，双头二芯 | 测试仪背面“风扇” |
| 通用电源正负 | 转接盒励磁区“IM电流输入”正负 |
| 转接盒“IM电流输出” | 平台励磁正负柱 |
| 测试仪前“IS电流输出” | 转接盒霍尔区“IS电流输入” |
| 转接盒“VH/VS电压输出” | 测试仪前“VH/VS电压输入” |

1. 转接盒置VH，方向开关先正向，电源两旋钮逆时针到底，控温保持关，风扇连接核对后按规程上电。
2. 记当天环境温度，在允许范围选至少六个温度，由教师确认；安排同一控温模式连续测量，减少冷热反转。

### 2. 稳定温度与磁场

1. 主菜单“温度设置”→OK，选升温或降温及目标，再开前面板控温，回主菜单进“霍尔/磁阻效应测量”。IS先设2.00 mA。
2. 本套指导书要求通用电源电压旋钮顺时针至最大，再调电流至0.300 A；仅在已确认本型号接线和限流状态后执行，其他型号按本机说明。记录正负方向实测B1、B2及励磁设置。课程有效场 $B=(B_1-B_2)/2$；原读数符号必须保留。
3. 到目标后继续等待约5分钟，确认实际腔温稳定，记录实际温度和环境温度。显示瞬间到目标不能当热平衡。

### 3. 每电流按固定顺序记录四向电压

1. 电压表正方向固定，依次记录V1（+IS,+IM）、V2（−IS,+IM）、V3（−IS,−IM）、V4（+IS,−IM），保留全部符号；方向切换依本机规程，不擅自带电拔线。
2. 算 $V_H=(V_1-V_2+V_3-V_4)/4$。构造例−0.126、+0.246、−0.206、+0.286 mV，得−0.216 mV。不能先对各原数取绝对值。
3. IS取2.0、2.2、…、4.0 mA共11点，每次增加0.2 mA后等至少1分钟，稳定后再读四向。各行记实际温度、IS、四电压与磁场。
4. 换励磁方向后对照起初B1、B2；差异大时按本机转接盒开关操作消除磁历史，使相应读数与起始值差在5 G以内再读。每温度完成一张完整表。换温前IS回2.00 mA；降温改升温或反向切换前先关控温，自然回到与环境温差小于5℃，再切模式，不能直接冷热强反转。

### 4. 每温度拟合，再拟合温度关系

1. G转T乘10⁻⁴，d核对课程1.25 mm=0.00125 m。每温度拟合 $V_H=aI_S+b$，电压用V、电流用A，得到 $R_H=ad/B$、$K_H=a/B$。
2. 构造例a=−0.0720 V/A、B=0.0900 T、d=0.00125 m，得RH=−1.00×10⁻³ m³/C、KH=−0.800 V/(A·T)。只有确认电流、磁场和电压坐标约定后才判断载流子类型。
3. 单载流子近似 $n=r_H/(e|R_H|)$，$r_H$ 是霍尔因子；课程未作修正时需声明取1。示例RH下n≈6.24×10²¹ m⁻³，不把近似当精确双载流子浓度。
4. 温度换K。只在可支持的本征温区、按指导书忽略缓变前因子时，拟合 $Y=\ln(|R_H|/R_*)$ 对 $x=1/T$，$R_*$ 为统一单位参考，斜率aT给 $E_g\approx2k_Ba_T$。变号、近零或杂质导电段不可直接混拟。
5. 构造例：横轴1000/T时斜率为1.000，换为1/T斜率1000 K，取kB=8.617333262×10⁻⁵ eV/K，得Eg≈0.17235 eV。若漏横轴1000倍率，结果会差1000倍。
6. 迁移率还需同温度电导率/电阻率：$\mu_H=\sigma|R_H|=|R_H|/\rho$。当前霍尔扫描没有独立纵向电阻及几何时，标记该量待测，不能由RH和厚度单独算出。
7. 报告附至少六套四向表、各温度VH—IS图、温度拟合及选区，保留温控和磁场条件。完成后IS及励磁回规定最小，关控温、按规程回温和断电，保存原表。

## 三、注意事项与问题查询

| 现象或问题 | 优先检查与处理 |
| --- | --- |
| 四向处理仍很散 | 查温度漂移、等待、自热及是否四向次序对应，不先改符号求直线 |
| RH量级错 | 查G转T、mm转m、mV/mA；两者同时换V/A时斜率数值不变，只换一列会差1000倍 |
| 灵敏度与什么有关 | 电流相关KH=RH/d受材料、温度和厚度影响；固定IS的电压对B灵敏度为IS·RH/d，勿混定义 |

依据：本目录实验十三指导书的装置接线、四向法和温控要求；至少六温度以2026秋模板为准。
