# 太阳能电池基本特性完成教程

## 一、实验目的与原理

比较单晶硅、非晶硅电池的暗伏安、开路/短路光强关系和负载输出特性。暗态由外加源供电；光照输出由电池发电，必须撤去外加源。输出功率 $P=VI$，最佳负载 $R_m=V_m/I_m$，填充因子 $FF=P_{\max}/(V_{\rm OC}I_{\rm SC})$，转换效率 $\eta=P_{\max}/(GS)$，$G$ 为辐照度W/m²，课程面积 $S=0.050\times0.050=0.002500$ m²。

预习要点：PN结内建场帮助分离、收集光生电子空穴；开路电压对应外部电流近零，短路电流对应端电压近零，二者乘积不是某个实际工作点的输出功率。

## 二、实验步骤

### 1. 预热并连接暗态回路

1. 开碘钨灯，至少预热20分钟，电池加遮光罩。灯工作及关闭后约1小时仍烫，勿摸灯罩或遮挡散热；遮电池不能变成罩住热灯。
2. 外加电压源归零关闭。按图6-6将外加源、50 Ω限流、电流表、电池串联，电压表并在电池两端。核对正负端和量程，再开源。
3. 电压/光强共用表头时，用测量转换及指示灯认显示量和单位，不从插口位置猜功能。

### 2. 两种电池分别测暗伏安

1. 电池完全遮光。按**实际电池端电压**0、0.3、…、3.0 V取正向点，逐点记电压、电流和量程。接近快速导通区小心增压，遇超量程或本机限值先停止。
2. 源归零关闭后按规定交换极性，测0至−7 V，1 V间隔；不把正反全范围均设成0.3 V，也不追求反向击穿。
3. 换第二种电池重复。画暗I—V图，保留电压与电流符号；低于量程分辨率写未分辨，不补理论零。

### 3. 八个位置测光强、开路与短路

1. 外加源归零关闭并从回路完全撤去。光强探头放在电池实际受光面位置、同高度朝向，测15、20、25、30、35、40、45、50 cm八处，记实际G及单位。
2. 换电池，只并高输入阻抗电压表，以开路接法在八处读 $V_{\rm OC}$；再按图6-7B接串联电流表形成规定短路回路，在同八处读 $I_{\rm SC}$。
3. 第二种材料同样完成，换样时避免额外受热并核对光强未明显漂移。分别画 $V_{\rm OC}$—G与 $I_{\rm SC}$—G；不能用距离平方反比生成光强代替实测。

### 4. 固定光照，通过负载扫输出特性

1. 选固定位置如40 cm，实测该组G。按图6-8接电池、电流表、电阻箱负载，电压表并电池；外加源保持撤去。
2. 从小负载接近短路的点开始，逐步加阻，使端电压约每0.2 V增加，直到接近开路。每点记实际R、V、I，不能用外加源设置输出电压。
3. 电阻最大仍未到开路时，保留该有限负载点，另按开路接法测端点；不要把电流强改为0。最大功率附近按教师要求补点，至少覆盖转折两侧。
4. 第二种电池在相同位置、光强条件下重复，记录参考光强及受照时间。

### 5. 求最大功率、最佳负载、FF和效率

1. V乘mA得mW，逐点算功率后找最大实测点，作输出I—V及P—V图。插值峰值须另标，不能填回原始表。
2. 构造算例：最大点1.20 V、38.0 mA，$P_{\max}=0.0456$ W、$R_m=1.20/0.0380=31.58$ Ω；同条件开路2.00 V、短路50.0 mA，则FF=0.456。若G=200 W/m²，入射功率=0.500 W，效率9.12%。全部数字仅示范。
3. 报告按三类数据整理两种材料的曲线、最大点及计算，比较必须基于本次同条件数据。先归零关输出，再按规程关灯、收纳，保留原始表。

## 三、注意事项与问题查询

| 现象或讨论 | 优先检查与回答 |
| --- | --- |
| 效率超过100%或数量级错 | 查mA转A、面积mm²转m²、光强表倍率，以及探头和电池是否同受光面 |
| 同位置读数爬移 | 查预热、受照温升、遮挡与接触，稳定后读，记录时序 |
| 如何找最佳负载 | 由每点VI找最大点，再算该点V/I，不能分别取最大V和最大I |
| 哪种电池输出更高 | 用同照明下实测最大功率回答，并结合材料、温升、有效受光与组件差异解释，不能预设排名 |
