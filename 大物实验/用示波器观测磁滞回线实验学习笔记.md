# 用示波器观测磁滞回线完成教程

## 一、实验目的与原理

观察两种环形样品的动态磁滞回线，求剩磁和矫顽力，用各小回线顶点绘基本磁化曲线。剩磁是 $H=0$ 时的 $B$；矫顽力是使 $B=0$ 的反向场强幅值。励磁电流由取样电阻测得，感应电压经过RC积分后反映磁感应强度：

$$
H=\frac{N_1U_x}{LR_1},\qquad B=\frac{R_2C}{N_2S}U_y.
$$

这里 $L$ 为平均磁路长，$S$ 为截面积，$N_1,N_2$ 为绕组匝数；$U_y$ 正方向按接线校正。积分近似要求 $R_2C\gg1/f$。

## 二、实验步骤

### 1. 断电连接并核对两轴

1. 信号源幅度最小、关闭输出，按指导书图3-2连接。操作段“图8-2”为错号，应查本章实际图。

| 支路 | 连接及用途 |
| --- | --- |
| 励磁 | 信号源、励磁绕组N1、取样电阻R1串联 |
| X输入 | R1两端电压送本机指定X通道 |
| 感应积分 | 感应绕组N2接R2—C网络 |
| Y输入 | 电容C两端电压送本机指定Y通道 |

2. 共地与绕组极性按本机端子和图核对，不能把示波器公共地夹到两个不同电位节点。记录R1、R2、C、样品L/S/N1/N2及探头倍率。
3. 经检查后上电预热5分钟，选样品1、40 Hz；先用时间扫描确认两路都有稳定、不削顶的波形，再切X-Y。按本机说明确认X/Y通道分配，查原点及倍率是否已经计入显示。

### 2. 退磁并采样品1的40 Hz数据

1. 在允许范围内缓慢增幅至饱和，再连续缓慢减幅，使回线缩成一点，完成交流退磁；直接关输出不能代替退磁。
2. 从小幅度重新增幅，直到继续增加H而B增长趋缓。选两轴量程，使顶点横向至少3格且整条回线不出屏；硬截顶先查电子限幅。
3. 沿一支从正顶点到负顶点，再沿另一支返回，至少取20点，交轴附近加密。记点号、支路、相对原点格数、V/div和截图。
4. 再退磁，由小到大形成一系列稳定小回线，每条只读第一象限顶点，样品1至少10组。顶点序列才是基本曲线，不能从一条大回线上挑点代替。

### 3. 换样品与频率

1. 幅度归零，按规程关输出或断电换样品2，核对其L、S和匝数，重新查零点并退磁。
2. 样品2在40 Hz取至少20点饱和回线；基本曲线按新模板取**20组顶点**。旧稿收尾“样品2至少10组”与新表不一致，以20组执行。
3. 按指导书补做样品2的100 Hz回线：先退磁、降至最小输出再改频率，重查积分条件和两路波形，采至少20点。该组附在模板后，不覆盖40 Hz记录。

### 4. 换算物理量并求截距

1. 每点按有效标度算 $U_x=x_ds_x$、$U_y=y_ds_y$，再代入开头公式。mm转m、cm²转m²、μF转F，勿重复乘探头倍率。
2. 构造例采用样品1参数 $N_1=N_2=150$、$L=0.130$ m、$S=1.24\times10^{-4}$ m²，另假设R1=10.0 Ω、R2=100 kΩ、C=10.0 μF。横3.20格×0.200 V/div得0.640 V；纵2.30格×2.00 mV/div得0.00460 V，算得 $H=73.8$ A/m、$B=0.247$ T。元件示例不能代替现场档位。
3. 图横轴H（A/m）、纵轴B（T），回线按支路相连。H=0读两侧剩磁，B=0读两侧矫顽力；交点落在两数据点间时按同一支局部线性插值，先分别保留符号，再求平均幅值。
4. 报告附三组回线、两组基本曲线、原数与设置，比较同频率、可比饱和条件下的参数。关机前减幅至最小，再关输出、断电、拆线。

## 三、注意事项与问题查询

| 现象或讨论 | 优先检查与回答 |
| --- | --- |
| X-Y只有直线 | 回时间模式分查两路，查通道分配和是否接到同一节点 |
| 回线打结或截平 | 核算RC与周期、查积分支路及源失真；扩大显示范围区分出屏与真正限幅 |
| 如何判断硬磁、软磁 | 在相同频率及可比饱和条件下比较Hc；低Hc、窄回线通常更接近软磁特征，不能只比屏幕格数 |
| 为何退磁 | 消除前次磁化历史；用逐渐衰减交变场建立可重复起点，不能以移动示波器零点替代 |
