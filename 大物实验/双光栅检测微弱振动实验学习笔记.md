# 双光栅检测微弱振动完成教程

## 一、实验目的与原理

用双光栅拍信号测音叉振幅，在固定驱动下测九点幅频曲线。课程所选光路中，一个拍周期对应动光栅移动一个栅距。密度 $n_g=100$ 条/mm时，单向机械半周期的路程为2A，故 $A=N/(2n_g)$；CH2电压高度影响可见度，不能直接当机械振幅。

预习要点：固定驱动下同一机械半周期拍数最多，对应振幅最大，是谐振判据；动光栅产生多普勒频移，静光栅提供对应衍射路径。两束不同频率光叠加可产生差频拍信号；动光栅使相关衍射光频率随速度改变，拍数累计反映路程。必须区分机械振动周期与拍波周期。

## 二、实验步骤

### 1. 最小驱动下连接并调光

1. 幅度最小，按规程关闭输出或断电接线。激光器用专用半导体电源，禁止直视光束或把反射光引向他人。

| 起点 | 终点 |
| --- | --- |
| 测试仪“波形输出” | 示波器CH1，作为驱动参考和触发 |
| 测试仪“输出I” | 示波器CH2，显示拍信号 |
| 测试仪“主输出” | 音叉驱动器 |
| 光电传感器 | 测试仪“信号输入” |

2. 光路依次为激光、静光栅、动光栅、接收器。调到透过两光栅产生竖排光斑，让中央最亮光斑进入传感器；微调平行度与接收位置，使CH2清楚稳定。不能随意改收另一光斑后仍套原系数。
3. 按指导书把音叉与驱动器间隙调约0.15 mm，可用白纸辅助定位后取出，具体以装置检查为准。小驱动下必须无碰撞。

### 2. 找谐振点并建立计数窗口

1. 选正弦，从约500 Hz附近缓慢扫频。保持驱动幅度旋钮不动，每次等波群稳定；比较同样机械半周期内的拍数，找最大附近频率 $f_r$。
2. 用CH1触发，调时基使机械周期可见，CH2峰谷不削顶且相邻拍波可分辨。CH1只提供周期参考，转向边界要结合CH2拍频最低的邻域辨认，不能把某个固定驱动相位当所有频率的转向点。
3. 选择相邻两机械转向点间的**单向半周期**。存整段波形、首尾局部放大图和实际频率；半周期应约为 $1/(2f)$。放大时保留端点对应，避免把局部图的一整屏当原窗口。

### 3. 计算首尾分数和总拍数

1. 每个端点分别读局部峰值 $U_{\max}$、谷值 $U_{\min}$ 和端点电压 $U_e$，算中线 $U_0=(U_{\max}+U_{\min})/2$、局部振幅 $V_a=(U_{\max}-U_{\min})/2$、归一化高度 $r=(U_e-U_0)/V_a$。
2. 采用局部正弦相位，反正弦角 $\alpha=\arcsin r$。端点处上升用 $\psi=\alpha\pmod{360^\circ}$，下降用 $\psi=180^\circ-\alpha\pmod{360^\circ}$；先由附近波形判走向。高度相同但走向不同，不能用同一分数。
3. 统一以“向上过中线”为参考相位。首端到其后第一个参考点的分数 $q_s=(360^\circ-\psi_s)/360^\circ$，若首端恰为参考点则取0；末端前最后一个参考点到末端为 $q_e=\psi_e/360^\circ$。只在两个参考点之间数完整周期M，$N=q_s+M+q_e$，不把首尾重复计入M。
4. 构造例：首端r=0.600且上升，$\psi_s=36.87^\circ$、$q_s=0.89758$；末端r=0.500且上升，$\psi_e=30^\circ$、$q_e=0.08333$；中间M=14，得N=14.98091，记录14.98。于是 $A=14.98091/200=0.07490$ mm=74.90 μm。示例不是实测。

### 4. 固定驱动采九点并作图

1. 按指导书围绕 $f_r$ 取 $f_r-0.4$ 至 $f_r+0.4$ Hz，间隔0.1 Hz，共九点。每点记录实际频率，重新辨机械转向边界，保留首数、M、尾数、总数、A和图号。
2. 保持驱动、间隙和光路；不得为离峰点“补高度”而调幅。若为防撞必须降低驱动，用新的共同幅度重采整组。
3. 作A—f图，标九点与最大实测点。选做加软管改变有效质量时，重新找新峰，再围绕新峰测一组；不沿旧峰频率代替新曲线。
4. 模板保留波数表及幅频曲线，附至少一组可复算的首尾判读。驱动降到最小后按规程关输出、激光和示波器，保存原图。

## 三、注意事项与问题查询

| 现象或讨论 | 优先检查与处理 |
| --- | --- |
| CH1有、CH2无 | 中央光斑是否进接收孔、传感器是否接信号输入、CH2是否取输出I，再查驱动与平行度 |
| 波数差一倍 | 查半周期/全周期边界；全周期公式为A=N/(4ng)，不能与半周期混用 |
| 为何幅度旋钮固定 | 扫频要控制驱动条件，否则曲线同时混入激励改变 |
| 红绿激光是否改换算 | 在课程一级路径中波长从频移比例中消去，系数由栅距决定；换颜色仍需重新对光 |

原始端点不清或出现削顶时重新采集，不靠挑相位分支凑整数。依据：本目录实验四指导书图4-7至4-9、九点测量及报告模板。
