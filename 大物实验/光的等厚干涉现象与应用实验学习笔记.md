# 光的等厚干涉现象与应用完成教程

## 一、实验目的与原理

用牛顿环测平凸透镜曲率半径，选做空气劈尖测磁带厚度。空气膜两反射光中有一次半波损失，近似正入射时暗纹满足 $2t=j\lambda$。牛顿环暗环直径平方随序号线性增加；实际中心接触不理想时，采用环级差消除共同零级偏移。

预习要点：牛顿环对应同心等厚线；空气劈尖对应平行等厚线。测微螺杆换向有空回，正式读数必须沿同一方向。

## 二、实验步骤

### 1. 调清叉丝与圆环

1. 核对钠灯波长589.30 nm、读数显微镜分度及牛顿环装置。按实验室规程开灯，不按压透镜接触面。
2. 先调目镜使叉丝清楚，再调显微镜物镜使暗环清晰。微移眼睛，叉丝与环不相对滑动后再测。
3. 找环心，选择穿过圆心的扫描线，以暗带中心为统一瞄准位置。给暗环编连续相对序号，左右同号必须是同一环。

### 2. 单向完成两侧第31至10环读数

1. 例如选择从左向右：先退到左侧35环以外，再向右到左31环建立螺杆接合状态。
2. 向右依次读左31、30、…、10环；越过中心，继续向右读右10、11、…、31环。**序号先减后增，鼓轮方向始终不变。**
3. 每点先认序号、对暗带中心，再记主尺和鼓轮原数。每侧22个位置，记录于模板对应行；读数单位统一为mm。
4. 越过目标不反拧一点补数；标记受影响行，退到足够远后重新同向接近，必要时整段复测。离台前核对44个原位置及原表照片。

### 3. 用11组逐差计算曲率半径

1. 同序号左右位置求直径 $D_j=|x_{j,L}-x_{j,R}|$。
2. 按模板将31与20、30与19、…、21与10配成11对，序号差均为11：

$$
R_i=\frac{D_m^2-D_n^2}{44\lambda},\qquad
\bar R=\frac1{11}\sum_{i=1}^{11}R_i,\qquad
\lambda=0.00058930\,\mathrm{mm}.
$$

3. 构造算例：一对直径为8.000 mm与6.000 mm，平方差28.000 mm²，故 $R_i=28.000/(44\times0.00058930)\approx1079.86$ mm。实际须逐对列平方差、半径后求平均，不能只保留最终值。
4. 按11组结果计算均值A类标准不确定度：

$$
u_A(\bar R)=\sqrt{\frac{\sum_i(R_i-\bar R)^2}{11\times10}}.
$$

仪器允差、校准及波长分量仅在课程要求且有参数依据时另评定；没有这些依据时明确结果仅含A类。异常先查环号、错行、平方及单位，不擅自删点。

### 4. 选做：测空气劈尖厚度

1. 磁带夹于两平玻璃片一端形成小劈角空气膜。调到平直、平行且清晰的条纹，显微镜沿条纹法向测量；明显弯曲或不均匀时先检查压持和表面。
2. 按模板测第i与第i+10条暗纹的位置，间距 $b=|x_{i+10}-x_i|/10$，重复五次；另测接触棱到磁带处的有效长度 $L$，重复五次。记录原始端点和间隔数，不能用“条纹条数”代替间隔数。
3. 用平均值计算 $h=\lambda\bar L/(2\bar b)$，长度用同一单位。构造例：$L=30.00$ mm、$b=0.300$ mm，得 $h=0.029465$ mm。未做选做则按教师要求注明。
4. 按模板整理环号原表、11组逐差、均值和规定不确定度；选做另附条纹与长度数据。备份实测记录，收纳光学件并关灯。

## 三、注意事项与问题查询

| 现象或讨论 | 判断与处理 |
| --- | --- |
| 中心不是理想暗点 | 接触处可能有间隙；连续相对环号的逐差仍可消除共同偏移，勿强压透镜求暗点 |
| 曲率半径个别组突变 | 回查左右同号、31与20等配对和mm换算，保留原数及修正依据 |
| 为何测较大环级 | 可避开中心不规则和零级难辨，增大有效差量；太外圈过密也难读，不能概括为越大越准 |
| 波长增大有何变化 | 固定R和同一级次时，半径及同一对相邻级次的间距均正比于波长平方根，随波长增大而增大 |

禁止触碰光学表面。依据：本目录实验二指导书的牛顿环、空气劈尖测量和讨论题；环级配对以2026秋报告模板为准。
