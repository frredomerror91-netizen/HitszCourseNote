# 实验十一｜迈克尔逊干涉仪完成教程

> 先调两臂光点重合，再引入扩束器得到圆环。测波长要把千分尺读数换成镜面真实位移；测空气折射率要记压力差与条纹数；观察定域条纹的照片在现场保存。

## 一、要完成和交什么

| 类型 | 任务 | 必留成果 |
| --- | --- | --- |
| 必做 | 调单色点光源干涉并观察动镜变化 | 实际圆环、方向和疏密变化记录 |
| 必做 | 每 50 环记录一次位置，到 250 环 | 0、50、100、150、200、250 环六个千分尺原读数 |
| 必做 | 气室五个压差，每个三次条纹计数 | 压差—条纹数表、关系图与空气折射率 |
| 必做 | 钠灯观察定域等倾、等厚干涉 | 两类实际照片及判断理由 |

报告包含逐差求激光波长、与 632.8 nm 标称值比较、空气折射率计算、现象分析和指导书讨论题。这里 632.8 nm 是比较值，不能倒算一组位置去填原始表。

## 二、准备与启动前核对

准备干涉仪、He-Ne 激光、扩束器、白屏、钠灯与毛玻璃、气室与气路，选做另备白光源。先认动镜 M2、定镜、分束器、补偿板、千分尺和调角螺钉，查看行程和压力表量程。

本课程仪器动镜真实位移是千分尺读数变化的 1/20，气室长 80 mm，压力表量程 0—40 kPa；先与实物核对。这些比例和长度不能自动套给其他型号。激光不得直视，光学面不触摸；取放气室和连接气管按教师规程，未确认额定压差不加压。

## 三、先把圆环调出来

### 1. 把动镜置中程，让激光进入扩束器轴线

熟悉微动系统后，把动镜放行程中部，记录初始千分尺位置，避免随后计数到限位。调激光器高度与方向，使光束能通过扩束器小孔；此时用屏或规定靶面观察，不用眼睛沿束找孔。

### 2. 撤扩束器，先重合两列光点

把扩束器移出光路，放白屏，观察两镜反射形成的两列光点。轻调镜背螺钉，使相应光点对应重合，不是只让某两个无关光点碰在一起。再把扩束器放回，观察圆环。

若出现过密或难辨条纹，按指导书在允许行程内调整定镜微调，取得合适疏密；再用动镜背面小调节把环心移到屏中央。一次只动一个明确功能，记主要调整。

**完成标志与取证：**圆环清晰、中心可辨且稳定，保存实际圆环照片。缓慢动镜，记录环是生出还是吞入、变密还是变疏，不能只抄原理图的箭头当观察。

## 四、单向计 250 环，逐差求波长

### 3. 选固定观察点，记六个原读数

选环心或指导书要求的固定位置作为计数基准，规定只数同类明纹或暗纹通过。先建立单向移动，记录 0 环位置，以后每同方向变化 50 环记一次，到 250 环。中途不换向补数；错数则重新建立计数起点，保留重测原因。

| 累计条纹变化数 | 0 | 50 | 100 | 150 | 200 | 250 |
| --- | --- | --- | --- | --- | --- | --- |
| 千分尺原读数/mm |  |  |  |  |  |  |

不要把已经除以 20 的位移填回“千分尺原读数”行。每次读完核对环数和位置方向一致，拍下最终原表备份。

### 4. 先除 20，再应用光程倍数

设千分尺原读数为 $s_i$、镜面真实位移为 $\Delta x$，条纹变化数为 $\Delta N$，激光波长为 $\lambda$。靠近中心小倾角时

$$
\Delta x=\frac{|s_j-s_i|}{20},\qquad 2\Delta x=\Delta N\lambda,\qquad \lambda=\frac{|s_j-s_i|}{10\Delta N}.
$$

这两个因子来源不同：20 来自传动比，2 来自往返光程，不能抵消错方向。六点可按 0 与 150、50 与 200、100 与 250 三对作逐差，每对跨 150 环，分别算波长再平均；若教师指定其他配对则按其方法，但须列出配对与环数差。

构造示例：若跨 150 环千分尺变化 0.9492 mm，镜面位移 0.04746 mm，得到 632.8 nm。这是计算演示，不是本次实测。报告列实际三对结果、平均值、参考偏差及所用有效数字。

## 五、测气压—条纹关系，再求空气折射率

### 5. 装气室并确认压力单位

按规程在定镜前放 80 mm 气室，检查装夹与气管后重新调清条纹。指导书压差点为 50、100、150、200、250 mmHg，气压表量程却用 kPa；先确定本机显示单位，换算后再操作，不能把“250”直接当 kPa 设。

课程压差范围约对应 6.7—33.3 kPa，仍须遵从本机额定压差与教师检查；这个换算用于认单位，不是新规定的压力上限。加压前记录起始压力与环境条件，辨清表压和绝对压。

### 6. 每个压差缓慢放回起点，计三次

按规定达到目标压差后，缓慢放气使压力表回起始位置，同时数固定观察点通过的同类条纹，精确到 0.5 环。每个压差重新建立起点并重复 3 次，不把一次计数拆写成三次。

| 压差/mmHg | 第 1 次条纹数 | 第 2 次 | 第 3 次 | 平均条纹数 | 起止压力与异常 |
| --- | --- | --- | --- | --- | --- |
| 50 |  |  |  |  |  |
| 100 |  |  |  |  |  |
| 150 |  |  |  |  |  |
| 200 |  |  |  |  |  |

**完成标志与证据：**15 次独立计数、单位和回到起始状态的记录齐全。放气太快造成漏数，应重新测该次，不用三次平均填回缺测。

### 7. 拟合斜率，注明课程环境压力口径

设气室长为 $l$，压差为 $\Delta P$，平均条纹数为 $N$，折射率变化为 $\Delta n$：

$$
N\lambda=2l\Delta n.
$$

作 N—ΔP 图，用图解或合理线性拟合求斜率 $a=\Delta N/\Delta P$。固定温度、近似理想气体并采用课程环境压力 $P_{\mathrm{amb}}=760\,\mathrm{mmHg}$ 时

$$
n_{\mathrm{amb}}=1+\frac{\lambda P_{\mathrm{amb}}}{2l}a.
$$

压差斜率与环境压力使用同一压力单位；若横轴改 kPa，环境压力也换成 kPa。λ、l 同用 m 或 mm。优先用前面测得的激光波长；若因缺测采用标称值，明确来源。760 mmHg 是课程指定比较条件，不称为现场实测气压。

## 六、钠灯定域观察与照片

### 8. 先区分光源，再调等倾与等厚

按规程停止激光相关观察，换钠灯、毛玻璃并移开扩束器。观察定域等倾时轻移视线，按指导书细调镜角，使条纹随视线平移、无明显吞吐；记录观察位置和实际特征。直接目视只限该钠灯扩展光源步骤，不可在激光未关闭时沿光路看。

等厚观察按指导书先用点光源得到圆环，调定镜微调使环逐渐缩进、变粗至很少，再稍改动镜角度，取得近似平行直条纹。记录镜角或位移改变时的现象。两种状态分别拍照，标明光源、观察位置与调整条件，不能只以“圆的是等倾、直的是等厚”代替定域判断。

白光为选做，只有实际观察后才附图与结论。切换光源和器件时按教师规程，避免在数环过程中改光路。

## 七、报告、排错和最终收尾

保留指导书讨论：镜位变化和观察位置变化在光程差 $\Delta L=2h\cos\alpha$ 中分别改了什么；圆环为何越外越密。这里 h 为两等效镜面的间隔，α 为观察倾角；用自己的现象分别联系 h 与 α，并说明中心附近角度变化的特点。

| 现象 | 优先检查 | 修正后判据 |
| --- | --- | --- |
| 两列光点不重合 | 扩束器是否撤出、镜背小调节与光轴 | 对应光点先重合再扩束 |
| 条纹漂移、计数困难 | 台面振动、气流、光源稳定与过密 | 稳定后重建计数起点 |
| 波长差 20 倍 | 原读数与镜位移是否混淆 | 原表不动，按比例重新计算 |
| 空气折射率异常 | 压力单位、环境压力、长度与波长单位 | 手算一个点并核对斜率单位 |

- [ ] 六个千分尺原读数、传动比和逐差配对明确。
- [ ] 五压差各三次，表压与单位已确认，没有越量程操作。
- [ ] 等倾、等厚实际照片及条件已保存，选做标明状态。
- [ ] 报告按教师格式提交并核对接收；气室回到规定状态后收管、关光源并保护光学面。
