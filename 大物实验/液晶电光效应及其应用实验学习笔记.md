# 液晶电光效应及其应用完成教程

## 一、实验目的与原理

观察显示子像素，验证马吕斯关系，测液晶扭曲角、电光曲线、响应时间和衍射结构周期。偏振片夹角为θ时，理想功率 $P=P_0\cos^2\theta$；扭曲向列液晶在不同驱动下改变偏振与透射。光开关测量必须固定偏振片，不能每个电压重新找消光。

预习要点：线偏振的电矢量沿固定方向振动；圆/椭圆偏振的端点随时间走圆/椭圆，部分偏振含有自然光成分。双折射是各向异性介质中不同本征偏振对应不同折射率。起偏器选择偏振方向，检偏器分析输出偏振；液晶具有介于普通液体和晶体之间的有序性，电场改变其取向。结构周期由衍射求得的是有效光栅周期，不是分子尺寸。

## 二、实验步骤

### 1. 观察子像素并建立光轴

1. 用放大镜观察显示器红、绿、蓝、白和暗画面，记录各RGB子像素亮暗组合与排列，按模板留图或画示意。
2. 驱动关闭，按激光器→起偏器→功率探头摆光路，连接专用电源，器件等高，光穿各中心进入探头。禁止直视光束或反射光。
3. 旋起偏器使透光最大，再插检偏器。等待功率稳定，若不稳先查预热、遮光和光斑是否落在孔边。

### 2. 测马吕斯关系及扭曲角

1. 无液晶时转检偏器找最小功率，记机械角，并把该位置定义为相对90°。据此回到相对0°，按0、10、…、90°测十点，功率记实际单位和暗端非零值，作P—θ曲线。
2. 两偏振片间插液晶盒，调高度使光从中心穿过。驱动关闭，转检偏器找消光机械角 $\alpha_0$。
3. 开液晶驱动，选连续、12 V，重新转检偏器找最小功率，记 $\alpha_{12}$。取两透振轴按180°周期等价的角差，并结合课程结构报告扭曲角。构造例137°与47°对应90°，不是未经测量即可填90°。

### 3. 固定光路测三次电光曲线

1. 保持12 V高驱动消光时的检偏器位置，从12 V逐档降低到最小，末尾关驱动测无场最大功率。中途不转偏振片。
2. 按模板电压栏取点，指导书明确标1、2、8、10、12 V，中间空栏细分由教师指定；过渡明显区按要求加密。整套扫描重复三次，保留方向和每次原功率。
3. 各电压先求平均功率，再以约定无场参考归一化 $T(V)=\bar P(V)/P_{\max}\times100\%$，画T—V图，按指导书常白模式定义，透射率90%对应阈值电压、10%对应关断电压；阈值在两实测点间可局部插值，写明所用两点，未覆盖阈值则补测。课程定义对比度 $C=P_{\min}/P_{\max}$，不可擅换成倒数。
4. 构造例：无场100 μW、某电压平均40 μW、最低2 μW，透射率40%，课程C=0.020。原始功率、本底和归一化结果分别保留。

### 4. 按光响应10%至90%计时

1. 用光探头替换功率探头，输出接示波器CH2；驱动参考信号接CH1。改间歇驱动，以CH1触发，调频率使CH2高低平台均能稳定，不削顶。
2. 确认探头极性，按“光强低、高”识别两平台。指导书定义光透射上升为10%到90%，下降为90%到10%，不能直接用驱动方波宽度。
3. 若电压随光强正向变化，平台为 $V_L,V_H$，阈值 $V_{10}=V_L+0.1(V_H-V_L)$、$V_{90}=V_L+0.9(V_H-V_L)$。用光标在同一边沿读两交点时间，相减得响应时间。
4. 构造例：平台0.20与1.20 V，阈值0.30、1.10 V；上升交点2.0、8.0 ms，上升时间6.0 ms。存整周期和局部图，图中须看清时基、CH1/CH2和阈值；负极性按光强映射重定阈值。

### 5. 测衍射周期并整理报告

1. 按规程撤下检偏器和探头，连续驱动约6 V，以白屏接光。微调驱动和液晶盒角度至一级衍射斑可辨，拍实际图样。
2. 量液晶盒至屏距离L，以及零级到一级的偏移x；若量左右一级总距D，应先取x=D/2。光栅近正入射时 $\theta=\arctan(x/L)$、$d=\lambda/\sin\theta$，波长取本机激光标识。
3. 构造例：假设λ=650 nm、L=0.500 m、x=0.0100 m，得d≈32.51 μm。它是该图样条件下有效周期；强倾斜条件不能直接套正入射式。
4. 按模板整理六项结果，附马吕斯、电光曲线、响应波形、衍射照片和计算。先关闭液晶驱动，再按实验室顺序关闭激光及仪表，保存原图。

## 三、注意事项与问题查询

| 现象或讨论 | 优先检查与回答 |
| --- | --- |
| 暗端功率不为0 | 查杂散光、消光位置和探头本底，先保留实数，不直接扣成0 |
| 响应时间随间歇频率变很多 | 查高低平台是否到稳态、时基、触发及探头带宽，再确认是光通道计时 |
| 矩阵显示原理 | 行列寻址改变像素驱动，RGB子像素经滤色与亮度控制组合颜色；刷新率不能直接等同液晶响应时间 |
| 液晶分类 | 按形成条件分热致、溶致；按取向/层状有序分向列、近晶、胆甾等，围绕本实验TN扭曲取向说明即可 |
