# 电子荷质比的测定完成教程

## 一、实验目的与原理

用电子圆轨迹和亥姆霍兹线圈求电子荷质比绝对值Q。电子从近静止经U加速，$eU=mv^2/2$；速度垂直磁场时 $evB=mv^2/r$，合并得：

$$
Q=\frac em=\frac{2U}{B^2r^2}=\frac{2U}{K^2I^2r^2},\qquad
K=\mu_0\left(\frac45\right)^{3/2}\frac{N_c}{R_c}.
$$

两相同线圈同轴、同向通电、间距等于线圈半径Rc时，中心附近磁场较均匀。Nc为每只线圈匝数，r是电子轨迹半径，两者勿混。K优先取本机校准或核实参数。

## 二、实验步骤

### 1. 断电接线、预热并调出圆束

1. 各输出归最小，按图12-2把灯丝、加速、聚焦、照明及励磁分别接同名端，线圈按规定同向串联；资料未清楚给出的聚焦接口请教师确认，不按插孔位置猜。
2. 图示型号灯丝约6.3 V，加速可调0—250 V、聚焦0—20 V，励磁短时最大3.5 A；这些是识别参数与限制，不是默认全开值。经检查上电预热约5分钟。
3. 本型号指导书以约130 V起束、稳定后可降到90—100 V为参考，当次仍以标牌及教师要求为准。先看零励磁轨迹，再小幅加励磁、调允许的聚焦，使轨迹清楚。保持束与磁场垂直，避免螺旋轨迹。
4. 记录线圈半径、间距、每只匝数或校准K、电压电流单位。原始记录有修订版时注明采用版本及原因，不混用修订前后数据。

### 2. 用反射镜消视差读绝对半径

1. 调后方反射镜使尺像清楚。移动滑尺和眼睛，使黑白分界中心刻线、所瞄电子束位置、反射像满足课程“三点一线”，然后读数；换端点需重新消视差。
2. 按图12-6记录枪口参考与对侧端点，或按本机允许的左右端点法记录SL、SR。确认两点构成过圆心的直径，$r=|S_R-S_L|/2$；束与其反射像不是圆的两端。
3. 原表记端点定义、坐标、当时U/I和束宽判读规则。构造例端点10.0、90.0 mm，直径80.0 mm、r=0.0400 m；不能把80.0 mm直接作半径。

### 3. 固定电压完成公式法

1. 固定允许的U，调电流使直径依次达到 $2r_0$、$2r_0+10$、$2r_0+20$、$2r_0+30$ mm，每次记实际I、U与几何记录。
2. 已直接测得半径时，逐行代入开头公式，再求平均。若只有直径增量，令半径增量δj为其一半，由固定U下 $I_0r_0=I_j(r_0+\delta_j)$ 得：

$$
r_0=\frac{I_j\delta_j}{I_0-I_j}.
$$

3. 构造例I0=2.00 A、Ij=1.60 A、直径增加20.0 mm，δj=10.0 mm，得r0=40.0 mm。按各增量分别求r0并依课程平均，再计算Q。
4. 单点换算示例：假设本机K=7.80×10⁻⁴ T/A、U=130.0 V、I=1.20 A、r=0.0400 m，则B=9.36×10⁻⁴ T，Q≈1.855×10¹¹ C/kg；示例参数不作为现场设置。

### 4. 固定半径作U—I²图

1. 选一个清楚且处于有效区域的目标半径，记录其绝对读径。每改U都重新调I，使同一束中心/规定边缘回到同一目标，重做消视差后记U、I和读径复查。
2. 横轴I²（A²）、纵轴U（V），按模板多组点拟合 $U=aI^2+b$，保留自由截距，$Q=2a/(K^2r^2)$。不固定r却套此式将失去依据。
3. 公式/反射镜法与作图法分别报告，和课程参考1.759×10¹¹ C/kg比较。分析U、I、r误差时，独立小误差下相对标准不确定度近似为：

$$
\frac{u(Q)}Q\approx\sqrt{\left(\frac{u(U)}U\right)^2+4\left(\frac{u(I)}I\right)^2+4\left(\frac{u(r)}r\right)^2+4\left(\frac{u(K)}K\right)^2}.
$$

4. 按模板保留直径增量表、固定半径U/I表和反射镜读径表，说明数据来源。输出按本机顺序降至最小，关机后拆接，保存原表。

## 三、注意事项与问题查询

| 现象或讨论 | 优先检查与回答 |
| --- | --- |
| 不是圆而是螺旋 | 束速度含平行B分量。若误把投影回旋半径代入全加速能量，理想模型Q偏高；按规程调整电子枪方向 |
| 半径读数随眼睛动 | 重做三点一线，查两端是否真为直径，不用猜测修正视差 |
| 其他测径方法 | 可用标定摄影拟圆；须校尺度、视角和畸变。反射镜法便于现场消视差，摄影便于复读但有几何校准成本 |
| Q数量级错误 | 先查mm转m、直径除2、K单位和励磁电流平方，再查背景场与束宽 |
