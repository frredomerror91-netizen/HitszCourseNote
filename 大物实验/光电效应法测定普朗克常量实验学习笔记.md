# 光电效应法测定普朗克常量完成教程

## 一、实验目的与原理

在2、4、8 mm三种光阑下各测五波长截止电压，分别用作图法和最小二乘法求普朗克常量。爱因斯坦方程 $eU_c=h\nu-W$ 给出 $U_c=k\nu+b$、$h=ek$；$e$ 为电荷量绝对值，$W$ 为逸出功。实际截距还可能含接触电势，不能无条件把它当纯材料逸出功。

预习要点：光子能量为 $h\nu$，截止电压对应最大初动能被反向电场阻止。固定频率增光强主要改变光电流；理想截止电压不随光强改变。

## 二、实验步骤

### 1. 遮光连接、预热和电流调零

1. 按规程关输出，暗箱电压输入接仪器后面板电压输出，红对红、黑对黑；暗箱微电流输出用专用高频屏蔽线接仪器微电流输入。先核对端口全名再上电。
2. 预热20分钟，方式选手动、内容选普朗克常数、电流量程选10⁻¹² A档。断开微电流输入线调零，再接回。电子学调零不等于扣除了接线后的暗电流。
3. 按规程启汞灯，光电管不用时遮光，不能长时间无控制受照。

### 2. 用“开—遮—开”补偿测第一组截止

1. 选2 mm光阑、365.0 nm滤片，电压从−2 V向+2 V范围内调节。记录波长、孔径、量程、实际电压符号和读数；正式模板截止栏按课程填绝对值。
2. **开光**，调电压使实测电流约0，记此时电压 $U_a$。
3. **遮光且保持 $U_a$**，记录暗/本底电流 $I_d$。
4. **开光**，调电压使实测电流等于所记 $I_d$，记截止电压 $U_c$ 及两种电流的差。每步等读数稳定；需要复核时重新执行整套补偿，不把遮光读数沿用到别波长。
5. 保存三步原始记录。差异小于分辨能力时记录可匹配电压区间，不能用显示相同宣称电流绝对为零。

### 3. 完成三孔径共15组

1. 在2 mm下依次换404.7、435.8、546.1、577.0 nm，重复同样补偿。
2. 再选4 mm、8 mm，各完成五波长；只变孔径和波长，其他几何保持一致。出现过量程先按本机规程处理并记录，不靠删去高光强组解决。
3. 按课程频率表使用8.216、7.410、6.882、5.492、5.196，单位均为10¹⁴ Hz，或由 $\nu=c/\lambda$ 计算并写清口径。

### 4. 每种孔径分别作图和拟合

1. 以 $x=\nu/(10^{14}\,\mathrm{Hz})$、$y=U_c$ 作五点图。作图法画反映全部散点的趋势线，用线上两个相距较远的点求斜率；不只连任意两个原始点。
2. 最小二乘拟合 $U_c=ax+b$，保留自由截距、斜率、残差及三孔径组别。由于横轴缩放，实际 $k=a\times10^{-14}$ V·s，故 $h=e a\times10^{-14}$。
3. 构造算例：若斜率a=0.414 V，则 $h=1.602\times10^{-19}\times0.414\times10^{-14}=6.63228\times10^{-34}$ J·s，相对课程参考6.626×10⁻³⁴ J·s约差0.095%。不把示例作为本次测量。
4. 三种孔径分别列两种方法结果、相对误差及差异。作图法直观但受画线与读点影响，最小二乘利用全体点且可看残差，但不能修复错误的补偿与单位。
5. 报告附15组记录、三组图和两种处理。结束时撤去光电管电压并遮光，再按规程关灯和电源。

## 三、注意事项与问题查询

| 现象或讨论 | 优先检查与回答 |
| --- | --- |
| 截止随孔径变化大 | 查暗电流、杂散光、滤片及匹配分辨率，先核对补偿记录 |
| 逸出功怎样求 | 理想模型中W=−eb；真实接触电势未独立校正时只能给模型有效估计 |
| 不同材料逸出功是否相同 | 不相同，取决于材料及表面状态；没有对应材料依据不作大小排序 |
| 真实实验影响因素 | 结合实际暗电流漂移、滤片带宽、杂散光、接触电势、仪表分辨率说明，不笼统归为人为误差 |

滤片与光电管保持清洁，勿摸光学面；汞灯关闭后待冷却再开。依据：本目录实验七指导书操作要点、报告要求和三道讨论题，以及2026秋模板。
