## 一、先安排多个视角：子图与布局（5.1—5.4）

### 本章路线

本章要解决的问题：怎样把多个图组织到同一画布且保留可比性？本章学完应会：区分画布与坐标轴，选规则或跨格布局，再决定共享范围。

### 学习单元

> 题源：依课程课件5.1—5.4及配套示例自编变式；本节小练习和检验同源，数据均为教学示例。

#### Figure、Axes 与数组下标

Figure 是整张画布；Axes 是实际承载曲线、刻度和标题的绘图区。`plt.subplots` 返回两者。默认压缩维度：1×1 返回单个 Axes，1×2 返回一维数组，2×2 返回二维数组。初学时加 `squeeze=False`，始终用“行、列”访问，编号从0开始。

下面的上图看销售额，下图看订单量；两者以同一月份对齐，但单位不同，不能共享纵轴。代码中的数据是示意值。

```python
import matplotlib.pyplot as plt
months = [1, 2, 3]
sales = [100, 150, 120]
orders = [10, 12, 11]
fig, axes = plt.subplots(2, 1, sharex=True, squeeze=False,
                         figsize=(7, 5), layout="constrained")
axes[0, 0].plot(months, sales, marker="o")
axes[0, 0].set_ylabel("Sales (yuan)")
axes[1, 0].bar(months, orders)
axes[1, 0].set_ylabel("Orders")
axes[1, 0].set_xlabel("Month")
axes[1, 0].set_xticks(months)
fig.suptitle("Monthly overview")
fig.savefig("overview.png", dpi=200)
plt.show()
```

核验：共2个绘图区，折线峰值150对应第2月，下方该月柱高12。`sharex=True` 共享的是横轴刻度、尺度和范围；不要求每个子图画同种图。`sharey=True` 只适合相同量纲且需要直接比较高低的纵轴。

##### 小练习：改动数组形状后怎样访问

将布局改为1×2，保留 `squeeze=False`，右图该用哪个下标？如果左边是元、右边是订单数，能否共享纵轴？

**答案：** 用 `axes[0, 1]`；不宜共享纵轴，因为数值的单位和含义不同。去掉 `squeeze=False` 后应改为 `axes[1]`，否则会发生维度索引错误。

#### 跨格布局让重要视角占更多空间

规则网格无法容纳“上排两图、下排通栏”时，用 GridSpec：它先划格，再用切片占格，切片右端不包含。`subplot2grid((2,2),(1,0),colspan=2)` 也能表达同样的下排跨列区域。

```python
fig = plt.figure(figsize=(8, 6), layout="constrained")
gs = fig.add_gridspec(2, 2, height_ratios=[1, 2])
a = fig.add_subplot(gs[0, 0])
b = fig.add_subplot(gs[0, 1])
c = fig.add_subplot(gs[1, :])
a.bar([1, 2], [4, 6])
b.scatter([1, 2], [2, 5])
c.plot([1, 2, 3], [4, 7, 5])
```

`height_ratios` 规定上下两行高度比例为1:2。`layout="constrained"` 在绘制时为标题、标签等安排空间；`tight_layout()` 是另一种常见布局方式，选一种即可，避免互相覆盖。保存后仍须检查长标签是否被裁掉。

##### 小练习：找出越界区域

在3×3网格里，`gs[1:, :]` 占几格？它能与 `gs[0, :]` 同时使用吗？

**答案：** 占第1、2行的全部三列，共6格；可以，上排与下两排不重叠。若另建 `gs[2, 1]`，便落入已占区域，可能叠图。

### 本章小结

先按比较任务选共享轴，再按信息重要性分配空间。布局确定以后，下一步处理局部放大、刻度与轴脊。

### 本章练习与检验

要比较两座城市同单位销售额并在下排放总额趋势，怎样安排？

**答案：** 上排两图比较时统一纵轴范围或共享纵轴，下排用跨两列的 `gs[1, :]`；趋势若是两市销售额之和，应标明“合计”，不能当第三座城市。

## 二、让坐标表达准确：画中画、刻度与轴脊（5.5—5.7）

### 本章路线

本章要解决的问题：怎样突出局部细节而不改变数据含义？本章学完应会：区分位置坐标与数据坐标，设置刻度位置、标签及轴脊。

### 学习单元

> 题源：依课程课件5.5—5.7及配套示例自编变式；本节小练习和检验同源，数据均为教学示例。

#### 任意位置坐标轴与局部放大

`fig.add_axes([left,bottom,width,height])` 的四个数按画布宽高归一化，范围通常在0到1之间；它们不是数据值。画中画是一个独立 Axes，需要重新画数据并设置局部范围。

```python
import matplotlib.pyplot as plt
x = [0, 1, 2, 3, 4]
y = [0, 1, 1.2, 1.1, 4]
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(x, y, marker="o")
ax.set(xlabel="Time", ylabel="Value")
small = fig.add_axes([0.20, 0.55, 0.28, 0.28])
small.plot(x, y, marker="o")
small.set(xlim=(1, 3), ylim=(0.9, 1.3), title="Zoom")
```

小图放大1至3时刻的变化，并没有将1.2变大；纵轴范围缩小使波动更容易看见。必须保留局部刻度，避免把0.2的变化误读为主图中的大幅跃升。手工定位的 Axes 需要自行检查遮挡，不能假定自动布局会替它安排好位置。

##### 小练习：还原画中画尺寸

画布宽10英寸、高6英寸，参数 `[0.6,0.5,0.3,0.25]` 对应多宽、多高？若主图数据最大值是100，会影响这些尺寸吗？

**答案：** 宽3英寸、高1.5英寸；与数据范围无关。这些数决定纸面位置，`set_xlim/set_ylim` 才决定显示的数据范围。

#### Locator 定位置，Formatter 定显示文字

刻度包含两个动作：在什么数据位置放刻度，以及把位置写成什么文字。已知固定位置时，`set_xticks([0,2,4], labels=["Start","Middle","End"])` 将两者配对；不能只换标签却让位置保持自动选择。

```python
from matplotlib.ticker import MultipleLocator, FuncFormatter
ax.yaxis.set_major_locator(MultipleLocator(1))
ax.yaxis.set_minor_locator(MultipleLocator(0.5))
ax.yaxis.set_major_formatter(FuncFormatter(lambda value, pos: f"{value:.1f}"))
ax.spines["top"].set_visible(False)
ax.spines["right"].set_visible(False)
```

主刻度每隔1，次刻度每隔0.5；`pos` 是格式化回调接收的位置参数，本例不使用。轴脊是绘图区边界线，隐藏它并不会删除数据。若画正负函数，可用 `ax.spines["left"].set_position(("data",0))` 将纵轴边界移到数据横坐标0；这与把它放到画布中央不同。`axis("off")` 会同时隐藏坐标装饰，不适合仍需读值的定量图。

##### 小练习：修正错误的刻度百分比

数据为0.1、0.2、0.3，想显示10%、20%、30%，回调只加 `%` 会怎样？应如何改？

**答案：** 会显示0.1%等错误值。用 `lambda v,p: f"{v*100:.0f}%"`；数据仍为原来的小数，只有显示文字换算。

### 本章小结

画中画改变观看范围；刻度格式改变显示文字；轴脊改变边界位置。它们都不应篡改原数值。

### 本章练习与检验

局部变化很小，放大后曲线很陡，能否据此声称增长速度超过主图其他阶段？

**答案：** 不能直接凭倾斜角判断，因为横纵比例可能不同。应比较同单位的数值增量与时间间隔，并写清小图范围。

## 三、增加维度与时间：三维图和动画（5.8—5.9）

### 本章路线

本章要解决的问题：第三个变量或变化过程怎样进入图形？本章学完应会：建立网格曲面，复用图形对象逐帧更新，区分静态帧与动画。

### 学习单元

> 题源：依课程课件5.8—5.9及配套示例自编变式；本节小练习和检验同源，数据均为教学示例。

#### 三维散点与曲面需要不同形状的数据

散点每个观测给一组 `(x,y,z)`；曲面要让每个网格位置都有一个高度。NumPy 的 `meshgrid` 将两条坐标序列扩成同形状矩阵，`plot_surface` 再将位置与高度配对。

```python
import numpy as np
import matplotlib.pyplot as plt
u = np.array([-1., 0., 1.])
X, Y = np.meshgrid(u, u)
Z = X**2 + Y**2
fig = plt.figure()
ax = fig.add_subplot(111, projection="3d")
surface = ax.plot_surface(X, Y, Z, cmap="viridis")
ax.set(xlabel="X", ylabel="Y", zlabel="Height")
fig.colorbar(surface, ax=ax, label="Height")
ax.view_init(elev=25, azim=40)
```

X、Y、Z 都是3×3；中心高度0，四角高度2。`elev` 是观察仰角，`azim` 是方位角；视角影响遮挡，不影响数据。三维图适合观察空间关系，精确比较多个高度时仍可改用二维热力图。

##### 小练习：不能直接拼成曲面

三个无规则观测 `(0,0,1)`、`(2,1,3)`、`(1,4,2)`，能否直接作为3×3规则曲面？应先选什么？

**答案：** 不能，9个格点的高度并未给出。先画三维散点；除非另有插值方法及适用依据，不补造其余位置的高度。

#### 动画每帧更新已有对象

动画由连续帧组成。先建一条线，`update(k)` 按第k帧修改其数据；不要每帧新建一张画布。`frames=20` 的帧编号为0到19，`interval=100` 表示目标帧间隔100毫秒，实际速度仍受环境影响。

```python
from matplotlib.animation import FuncAnimation
fig, ax = plt.subplots()
x = np.linspace(0, 2*np.pi, 100)
line, = ax.plot(x, np.sin(x))
ax.set_ylim(-1.2, 1.2)
def update(k):
    line.set_ydata(np.sin(x + 0.1*k))
    return (line,)
ani = FuncAnimation(fig, update, frames=20, interval=100, blit=False)
update(5)
fig.savefig("frame5.png")
plt.show()
```

第5帧在横坐标0的值是 `sin(0.5)`，约0.479；首帧是0。保存 `frame5.png` 只保存一个状态；保存动画需 `ani.save(...)` 及相应写入器，PNG不会自动播放。Notebook 的静态绘图后端也不会把动画直接变成可播放内容，需要另行输出动画或HTML表示；变量 `ani` 应保持引用。

##### 小练习：为什么看到静止图

创建动画后只把 `fig.savefig("a.png")` 放进文档，别人能看到20帧变化吗？怎样检查更新函数本身？

**答案：** 不能。先分别调用 `update(0)` 与 `update(5)` 检查同一位置的纵值，再导出支持播放的动画格式；静态报告可以并排展示选定帧。

### 本章小结

三维需要核对点与网格的形状，动画需要核对帧编号与对象更新。输出介质决定读者最终能看到什么。

### 本章练习与检验

将 `update` 改成每帧调用 `ax.plot(...)`，运行20帧可能出现什么？如何修正并验证？

**答案：** 会不断添加线，旧帧叠留；改为对既有 `line` 调 `set_ydata`，检查更新前后线对象数量仍为1，且第0、5帧数据不同。

## 四、用颜色比大小，用流宽讲去向（5.10—5.11）

### 本章路线

本章要解决的问题：矩阵和收支流量各应怎样编码？本章学完应会：固定热力图色标，检查行列方向，核对桑基流量平衡。

### 学习单元

> 题源：依课程课件5.10—5.11及配套示例自编变式；本节小练习和检验同源，数据均为教学示例。

#### 热力图必须交代行、列和色标范围

热力图将一个矩阵的数值映射为颜色。`imshow` 的第一维是行、第二维是列；默认第一行在上方。下面第0行是A店，第1行是B店，列依次是周一、周二。

```python
import numpy as np
import matplotlib.pyplot as plt
M = np.array([[10, 20], [30, 40]])
fig, ax = plt.subplots(layout="constrained")
im = ax.imshow(M, cmap="viridis", vmin=0, vmax=40)
ax.set_xticks([0, 1], labels=["Mon", "Tue"])
ax.set_yticks([0, 1], labels=["A", "B"])
for i in range(2):
    for j in range(2):
        ax.text(j, i, str(M[i, j]), ha="center", va="center", color="white")
fig.colorbar(im, ax=ax, label="Orders")
```

`text(j,i,...)` 是横坐标为列、纵坐标为行。跨图比较时固定相同的 `vmin/vmax`，否则相同深色可能对应不同值。有自然中点的正负变化适合发散配色如 `coolwarm`，例如固定-1到1的相关系数；非负数量适合顺序配色如 `viridis`。`viridis` 不是发散配色。

##### 小练习：颜色相同为什么数值不同

图甲最大值40、图乙最大值400，都自动缩放色标，最亮的格子能否直接比较？

**答案：** 不能。自动缩放只反映各自范围内的位置；统一范围或明确分别读色标，才不会把40当成400。

#### 桑基图先核对收支，再画宽度

桑基图以流带宽度表示数量。Matplotlib 的单个 Sankey 子图约定正数流入、负数流出；封闭收支示例应使带符号流量之和为0。

```python
from matplotlib.sankey import Sankey
fig, ax = plt.subplots()
Sankey(ax=ax, scale=0.01).add(
    flows=[100, -60, -40],
    labels=["Income", "Cost", "Balance"],
    orientations=[0, 1, -1]
).finish()
```

这里收入100=成本60+结余40，结余也是资金流出的一个去向。`orientations` 控制朝向，不负责规定收入或支出；`scale` 控制流宽比例。若收支差额未列出，先查是否有储蓄、损耗或遗漏，不能用改标签来掩盖数量不平衡。

##### 小练习：为差额找到明确去向

流入120、成本70、工资30，若另有结余，`flows` 应怎样写？

**答案：** `[120,-70,-30,-20]`；结余20使总和为0。四个标签与四个朝向也应一一对应。

### 本章小结

热力图的比较依赖统一色标，桑基图的解释依赖明确流向与平衡。先检查编码对应关系，再判断图形是否漂亮。

### 本章练习与检验

两个月订单矩阵的最大值分别20、80，要比较绝对订单水平怎样画？若要比较各月内部结构又怎样？

**答案：** 绝对水平使用统一0至80的色标；内部结构可先按各月总量计算占比并明确单位为百分比，不能继续标为订单数。

## 本章综合习题测验

> 题源：依本章课件和前述教学内容自编综合题；全部数据为给定教学数据，非课程项目实测结果。先遮住解析独立作答。

### 第1题：规划一页比较图

**题目：** 两店各有3个月销售额，另有两店合计订单量。要求上排比较两店销售、下排通栏显示订单，应怎样划分网格和共享轴？

**解析与答案：** 用2×2 GridSpec，上排 `gs[0,0]` 与 `gs[0,1]`，下排 `gs[1,:]`。上排销售额单位相同，统一纵轴范围；所有图以月份为横轴并对齐。下排订单数不能共享销售额纵轴，必须标单位。

### 第2题：审查放大图

**题目：** 主图纵轴0到100，小图纵轴9到11，小图从10升至11，主图另一段从20升至30，时间间隔都1。有人凭小图更陡判断其增长更快，怎样核验？

**解析与答案：** 两段增量分别1与10，单位时间增长分别1与10；小图纸面斜率受纵轴缩放影响，不能直接比较。保留小图范围标注，按数据增量判断第二段更快。

### 第3题：核验曲面与帧

**题目：** 网格横纵坐标均为[-1,0,1]，高度为 X**2+Y**2；动画更新为 sin(x+0.1*k)。求曲面中心、角点高度及第10帧x=0处纵值，并说明怎样输出动态过程。

**解析与答案：** 中心0，角点1+1=2；第10帧为sin(1)，约0.841。用动画写入器导出可播放格式或HTML；单个PNG只能展示第10帧，不能作为动画交付。

### 第4题：检查热力图与收支

**题目：** 两店订单矩阵为[[10,20],[30,40]]，行是门店、列是日期。指出B店第二日位置；资金流入200，三项支出80、50、40，补平衡项并说明两种图的编码区别。

**解析与答案：** B店第二日为M[1,1]=40，文字位置为(1,1)。差额30，应列结余流出，flows=[200,-80,-50,-40,-30]。热力图以色标映射每格数值；桑基图以流宽与方向表达数量去向，不能互换读法。

## 公式卡

- 归一化位置：画中画宽度=画布宽度×width，高度=画布高度×height。
- 单位时间变化=数值增量÷时间间隔；纸面斜率还受坐标缩放影响。
- 封闭单节点流量：所有带符号 flows 之和为0；正流入、负流出。
