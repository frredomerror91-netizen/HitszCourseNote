## 一、从表格到图：数据语义与接口层级（6.1）

### 本章路线

本章要解决的问题：怎样告诉 Seaborn 每列扮演什么角色？本章学完应会：使用长表与列名映射，区分指定坐标轴和自行创建画布的函数。

### 学习单元

> 题源：依课程课件6.1及配套示例自编变式；本节小练习和检验同源，数据均为教学示例。

#### 一行一个观测，列名指定变量

Seaborn 基于 Matplotlib，能直接接收 pandas DataFrame。下面一行代表一个App，`category` 是类别，`price` 是价格，`rating` 是评分，`type` 区分免费与付费；这类“观测逐行、变量逐列”的数据常称长表。`hue` 将一列映射为颜色分组，而不是把该列当纵坐标。

后文示例先执行这段公共代码；数据仅为教学构造，不是课件App数据的统计结论。

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
apps = pd.DataFrame({
    "category": ["Game", "Game", "Game", "Tool", "Tool", "Tool"],
    "price": [0., 10., 20., 0., 0., 30.],
    "rating": [4., 3., 5., 3., 5., 4.],
    "type": ["Free", "Paid", "Paid", "Free", "Free", "Paid"]
})
sns.set_theme(style="whitegrid", palette="colorblind")
fig, ax = plt.subplots()
sns.scatterplot(data=apps, x="price", y="rating", hue="category", ax=ax)
ax.set_title("Price and rating")
```

核验：有6个观测点，但部分点可能重叠；颜色分两类。`data=apps` 指整表，`x="price"` 指表中的列名，不能拼错大小写。

##### 小练习：识别变量角色

想比较各类别评分，并用免费/付费着色，三个角色应怎样指定？能否把 `hue` 写成某个颜色值来完成分组？

**答案：** `x="category", y="rating", hue="type"`；`hue` 应指定分组变量，固定颜色应用颜色参数设置，不能用一个颜色名代替分组列。

#### axes级可嵌入子图，figure级自建网格

`histplot/scatterplot/boxplot` 等 axes级函数能用 `ax=` 画进已有坐标轴。`displot/relplot/catplot` 等 figure级函数自己创建网格，常用 `col/row` 按变量拆成多个小图，这叫分面；其返回对象可调用 `.set(...)` 或 `.savefig(...)`。

```python
fig, axes = plt.subplots(1, 2, figsize=(8, 3), layout="constrained")
sns.histplot(data=apps, x="price", ax=axes[0])
sns.boxplot(data=apps, x="category", y="rating", ax=axes[1])
g = sns.catplot(data=apps, x="category", y="rating",
                col="type", kind="strip")
g.set(ylim=(0, 5.5))
```

第一张画布包含价格直方图与分类箱形图；`catplot` 另建画布并按type分两面。不要期待把 `catplot` 塞入 `axes[1]`。主题应先于绘图设置；`set_context("talk")` 用于放大汇报图文字等元素，不改变数据。

##### 小练习：为什么多出一张空画布

先 `plt.subplots()` 再调用不带 `ax` 的 `sns.displot(...)`，为什么原画布可能仍是空白？

**答案：** `displot` 自己建了另一张画布；要嵌入原图就改用 `histplot(...,ax=ax)`，要分面则直接保留 `displot` 返回的网格对象。

### 本章小结

先确认一行的含义，再给列分配坐标、颜色或分面。接口层级决定图画到哪里，后面才讨论图统计什么。

### 本章练习与检验

要做2×1报告页，上图价格分布、下图评分散点，选哪些函数？保存哪个对象？

**答案：** 用 `plt.subplots(2,1)` 建图，分别 `histplot(...,ax=axes[0])` 和 `scatterplot(...,ax=axes[1])`，保存 `fig`。不要混入自建画布的 `displot`。

## 二、从分布到关系：直方、密度、联合与成对图（6.2—6.4）

### 本章路线

本章要解决的问题：数据集中在哪里，两个变量又怎样一起变化？本章学完应会：读取分箱和密度，连接散点与边际分布，限制成对图变量。

### 学习单元

> 题源：依课程课件6.2—6.4及配套示例自编变式；本节小练习和检验同源，数据均为教学示例。

#### 分箱计数与密度不是同一种纵轴

直方图将数值划分成区间，每根柱对应一个区间。给价格 `[0,0,0,10,20,30]` 指定边界 `[0,10,20,30,40]`，按左闭右开计数为3、1、1、1；最后一个区间包含最右端点。

```python
fig, ax = plt.subplots()
sns.histplot(data=apps, x="price", bins=[0, 10, 20, 30, 40], ax=ax)
```

默认 `stat="count"` 看个数。`stat="density"` 将总柱面积归一为1，本例每格宽10，因此柱高为0.05、1/60、1/60、1/60；柱高不能直接读成该区间的概率。要读概率，乘区间宽度。

核密度估计（KDE）用平滑曲线估计分布形状；带宽影响平滑程度，不能把曲线每个小峰都当成真实分群。价格非负，平滑曲线可能越过0，可限制绘制范围，但这不自动解决边界估计问题。小样本或大量0价格时，先看直方图和原始点。

```python
fig, ax = plt.subplots()
sns.histplot(data=apps, x="price", stat="density", bins=4, ax=ax)
sns.rugplot(data=apps, x="price", ax=ax)
```

`rugplot` 在轴边标记观测位置。课件参数速查把 `rug` 与直方图并列，但 `histplot` 不直接接收 `rug=True`；需要单独叠加 `rugplot`，或使用支持该参数的 `displot`。

##### 小练习：改变箱宽后能否直接比柱高

两区间宽分别5和10，各含10个样本，共20个观测，密度柱高各为多少？哪个区间概率更大？

**答案：** 分别10/(20×5)=0.1、10/(20×10)=0.05；概率均为0.5。较高柱子不意味着更大概率，还要乘宽度。

#### 关系图先保留逐条配对

散点 `(price,rating)` 必须来自同一行；分别排序两列会制造虚假关系。`jointplot` 将二维关系放中间，将各变量单独的分布放边缘，边缘只概括单变量，不能代替中间的配对关系。

```python
g = sns.jointplot(data=apps, x="price", y="rating", kind="scatter")
p = sns.pairplot(apps, vars=["price", "rating"],
                  hue="category", diag_kind="hist")
```

`kind="hex"` 用六边形分箱缓解大量散点重叠；`kind="kde"` 看二维密度；`kind="reg"` 中间加回归线，但默认边际仍是单变量直方图，不是“两条回归图”。成对关系图 `pairplot` 对角线看每列分布，非对角线看两列关系；选2列形成2×2网格。变量很多时先用 `vars` 选业务相关列，避免把无意义的编号当连续数值解释。

##### 小练习：相关性为何突然完美

两列原配对为 `(0,5),(10,1),(20,4)`，分别升序排列后画图得到 `(0,1),(10,4),(20,5)`，能否作为原关系证据？

**答案：** 不能，原行对应被打乱。应保留同一行的配对；排序整个DataFrame只改变点的排列顺序，独立排序两列却改变了点本身。

### 本章小结

分布图回答一个变量怎样分布，关系图回答两个变量怎样配对。分箱、带宽和重叠会影响外观，解释必须回到观测与尺度。

### 本章练习与检验

6个价格中有3个0，能凭KDE峰最高就说“0元概率大于1”吗？怎样给出可核对说法？

**答案：** 不能，密度高度不是点概率。直接计数可说本教学样本6个App中3个免费，占50%；连续密度曲线只是形状估计。

## 三、比较类别：观测、分位数和统计估计（6.5—6.7）

### 本章路线

本章要解决的问题：类别之间应比较个数、均值还是分布？本章学完应会：选分类散点、箱形、小提琴、柱形或点图，并说明误差棒。

### 学习单元

> 题源：依课程课件6.5—6.7及配套示例自编变式；本节小练习和检验同源，数据均为教学示例。

#### 原始点与箱形图保留的信息不同

`stripplot` 在分类轴轻微抖动位置，纵值保持不变；`swarmplot` 尝试排开点以减少重叠，但密集时可能放不下，不能保证任意数据都完全无重叠。前者适合较大样本，后者适合较小样本。

箱形图用下四分位数Q1、中位数Q2、上四分位数Q3概括数据：25%、50%、75%分位数分别表示相应位置。四分位距 IQR=Q3−Q1。默认须延至不超过 Q1−1.5IQR 与 Q3+1.5IQR 的最远实际观测；超出者单独显示。须不一定就是最小、最大值，离群点也不自动等于错误数据。

若给定Q1=10、Q2=12、Q3=14，则IQR=4，界限4和20；观测最小5、最大30，且界内最大18，则下须5、上须18、30单独标出。

```python
fig, ax = plt.subplots()
sns.boxplot(data=apps, x="category", y="rating", ax=ax)
sns.stripplot(data=apps, x="category", y="rating",
               color="black", jitter=True, ax=ax)
```

小提琴图 `violinplot` 用宽度展示估计密度，`inner="quartile"` 标四分位线。宽处代表该纵值附近密度较高，不能在默认设置下一律解释为该组样本更多；特别是每组只有3条的教学小表，应保留原始点，不把平滑外形当成可靠总体形状。

##### 小练习：离群值能否直接删除

已给Q1=20、Q3=30，观测含5和50，两者是否越界？能否仅因标成离群点就删掉？

**答案：** IQR=10，界限5、45；5恰在界限内，50在外。50需查量纲、录入和业务情境，不能仅凭图形删除。

#### countplot 数行，barplot 默认求均值

`countplot` 统计各类别观测数；`barplot` 默认在每类内计算纵变量均值；`pointplot` 用点和误差棒呈现估计值，适合比较组间变化。点之间的连接不自动意味着时间顺序或因果关系。

教学表中两类各3个App，Game价格均值=(0+10+20)/3=10，Tool均值=(0+0+30)/3=10。计数相同、均值相同，也不能证明价格分布相同。

```python
fig, axes = plt.subplots(1, 2, layout="constrained")
sns.countplot(data=apps, x="category", ax=axes[0])
sns.barplot(data=apps, x="category", y="price",
             errorbar=None, ax=axes[1])
```

误差棒表示什么由参数决定。课程采用 `errorbar=("ci",95)` 表示均值的95%置信区间，反映估计不确定性，不是95%原始观测所处范围；`errorbar="sd"` 表示标准差，强调数据离散程度。本例为明确核验均值而关闭误差棒。Seaborn 0.12及以后使用 `errorbar`；旧环境应核对版本，不盲抄参数。

##### 小练习：总额和均值为什么排名相反

A类金额[10,10,10,10]，B类[15,15]，默认barplot谁更高？若问题是比较销售总额，怎样处理？

**答案：** 默认均值A=10、B=15，所以B更高；总额却A=40、B=30。应先按类求和再画普通柱形，或明确指定求和估计，标题与纵轴必须标为总额。

### 本章小结

类别比较先确定统计对象：每个观测、分布位置、均值或个数。误差棒与小提琴宽度都需要解释条件。

### 本章练习与检验

两组均值同为10，A为[9,10,11]，B为[0,10,20]。只画无误差棒均值柱够吗？

**答案：** 不够，两组离散程度差别很大。可用分类散点直接显示样本，或箱形图叠点；小样本下不要只靠平滑密度形状。

## 本章综合习题测验

> 题源：依本章课件和前述教学内容自编综合题；全部数据为给定教学数据，非课程项目实测结果。先遮住解析独立作答。

### 第1题：从问题安排接口

**题目：** 要同页比较价格分布与类别评分，并在另一页按免费/付费分面。应选什么接口？怎样设置主题和保存？

**解析与答案：** 同页用subplots，配histplot和boxplot/stripplot，传各自ax；分面页用catplot(col="type")。绘图前set_theme，同页保存fig，分面保存返回的g；不能用figure级函数替换现有ax而期待仍在同页。

### 第2题：从柱高恢复概率

**题目：** 四个等宽10的区间，个数为3、1、1、1。给出第一格计数、密度和概率，并判断改成更窄分箱后是否可直接比密度最高值。

**解析与答案：** 第一格计数3，密度3/(6×10)=0.05，区间概率0.05×10=0.5。分箱改变会改变密度估计峰高；跨图比较先对齐区间与归一化口径，不能用峰高直接替代概率。

### 第3题：核验箱须与异常点

**题目：** 给定Q1=10、Q2=12、Q3=14，观测范围5到30，界内最大18。写IQR、界限、须位置；若30是合法大单，如何展示？

**解析与答案：** IQR=4，界限4和20，须为5和18，30为离群点。保留30并说明业务含义，可叠原始点；showfliers=False只隐藏标记，并未删数据，不能借此声称没有大单。

### 第4题：审查汇报结论

**题目：** A类价格[0,0,30]，B类[0,10,20]，报告称“平均价格相同，所以分布相同，且95%CI覆盖95%的App价格”。指出两处问题并选补充图。

**解析与答案：** 均值都10，却有不同的免费比例与尾部；用stripplot和直方图补充。均值CI描述估计不确定性，不是观测覆盖范围。样本很小，应同时报样本数，不能据平滑小提琴外观推断稳定总体差异。

## 公式卡

- 均值=组内数值总和÷有效观测数；计数是观测行数。
- 直方密度=箱内个数÷（总观测数×箱宽）；区间概率=密度×箱宽。
- IQR=Q3−Q1；默认离群界限为Q1−1.5IQR、Q3+1.5IQR，须落在界内的实际观测。
