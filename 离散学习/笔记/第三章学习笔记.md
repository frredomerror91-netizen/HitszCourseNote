# 第三章｜命题逻辑的推理理论

## 本章要学什么

本章围绕一个可检验的问题展开：**给定若干前提，结论是否必然成立；如果成立，怎样把“必然成立”写成可复核的形式证明？** 学习顺序从推理的形式结构开始，先明确“有效”只排除“前提全真而结论为假”，再比较真值表、等值演算、主析取范式和反例赋值等判定方法，最后进入系统 $P$ 的逐行证明。

本章主线只覆盖第三章课件中的命题逻辑推理理论；真值表、范式和自然推理的细节以项目内课件为准，不把一阶逻辑的量词推理提前混入本章。学完后应能：

- 把自然语言推理整理为前提集合与结论，并写成前提合取蕴涵结论的形式；
- 根据变项数量、目标形式和是否需要反例，选择合适的有效性判定方法；
- 识别肯定后件、否定前件等无效推理，并给出一组反例赋值；
- 在系统 $P$ 中使用前提、等值置换和基本推理规则逐行构造证明；
- 对证明中的每一步标注依据，并用结论形式和反例检查结果。

> 阅读顺序：推理形式 → 有效性语义 → 判定方法 → 推理定律 → 系统 $P$ → 证明策略。

## 2. 推理的形式结构
### 本章路线

先写前提与结论，再把推理化为“前提合取蕴涵结论”，最后用赋值或等值式检查是否存在反例。

> 本章要解决的问题：有效推理只要求“前提全真时结论必真”，如何把这一定义落实为可计算的判定任务？
>
> 本章学完应会：能区分有效性与事实真值，并能说明某一赋值是否构成反例。


### 2.1 有效推理

设 $A_1,A_2,\ldots,A_k$ 是前提，$B$ 是结论。若对每一组赋值：

- 前提合取式 $A_1\land A_2\land\cdots\land A_k$ 为假；或
- 当前提合取式为真时，$B$ 也为真，

则称从 $A_1,A_2,\ldots,A_k$ 推出 $B$ 的推理是**有效的（正确的）**，$B$ 是这些前提的有效结论。

核心判定定理：

$$
A_1,A_2,\ldots,A_k\models B
\quad\Longleftrightarrow\quad
(A_1\land A_2\land\cdots\land A_k)\to B\text{ 是重言式。}
$$


### 2.2 三种常见写法

1. 集合式：$\{A_1,A_2,\ldots,A_k\}\vdash B$；若强调语义有效性，可写作 $\{A_1,A_2,\ldots,A_k\}\models B$。
2. 蕴涵式：$(A_1\land A_2\land\cdots\land A_k)\to B$。
3. 前提与结论分列：前提为 $A_1,A_2,\ldots,A_k$，结论为 $B$。

> **关键辨析**：推理有效只表示“不会出现前提全真而结论假的情况”。如果前提在现实中为假，有效推理的结论仍可能为假。

### 本章小结

能区分有效性与事实真值，并能说明某一赋值是否构成反例。 本节的公式、定义或判定应回到课件条件核对，不能脱离对象、范围和适用边界单独记忆。

## 3. 判断推理是否有效
### 本章路线

先用反例赋值快速否定，再用真值表/等值演算确认；对形式相近的规则比较其反例条件。

> 本章要解决的问题：为什么“肯定后件”和“否定前件”不能从表面语言直觉中直接接受？
>
> 本章学完应会：能为无效推理给出完整反例，并能解释反例必须同时满足哪些条件。


### 3.1 真值表法

把推理改写为

$$
(A_1\land\cdots\land A_k)\to B,
$$

列出全部赋值。若最后一列全为真，则推理有效；只要存在一行使前提全真而结论为假，推理就无效。

适用场景：命题变项较少，需要机械、可靠地判定。


### 3.2 等值演算法

对推理对应的蕴涵式使用等值式进行化简：

- 若最终化为 $1$，则它是重言式，推理有效；
- 若没有化为 $1$，且能看出存在成假赋值，则推理无效。

常用起手式：

$$
P\to Q\Leftrightarrow \neg P\lor Q.
$$


### 3.3 主析取范式法

将蕴涵式化为主析取范式：

- 若包含全部极小项，则为重言式，推理有效；
- 若缺少某个极小项，则对应赋值会使公式为假，推理无效。


### 3.4 反例赋值法

若只需证明推理无效，寻找一组成假赋值通常最快：

$$
A_1=\cdots=A_k=1,\qquad B=0.
$$

一组这样的赋值就足以否定推理的有效性。


### 3.5 典型辨析

假言推理是有效的：

$$
(p\to q)\land p\Rightarrow q.
$$

肯定后件不是有效推理：

$$
(p\to q)\land q\not\Rightarrow p.
$$

例如取 $p=0,q=1$，两个前提都真而结论 $p$ 假。

能为无效推理给出完整反例，并能解释反例必须同时满足哪些条件。 本节的公式、定义或判定应回到课件条件核对，不能脱离对象、范围和适用边界单独记忆。

## 4. 九类常用推理定律
### 本章路线

先用反例赋值快速否定，再用真值表/等值演算确认；对形式相近的规则比较其反例条件。

> 本章要解决的问题：为什么“肯定后件”和“否定前件”不能从表面语言直觉中直接接受？
>
> 本章学完应会：能为无效推理给出完整反例，并能解释反例必须同时满足哪些条件。


| 名称       | 形式                                                                             | 识别要点                       |
| ---------- | -------------------------------------------------------------------------------- | ------------------------------ |
| 附加律     | $A\Rightarrow A\lor B$                                                         | 已知一个支项，可扩大为析取式   |
| 化简律     | $A\land B\Rightarrow A$；$A\land B\Rightarrow B$                             | 从合取式取出任一支项           |
| 假言推理   | $(A\to B)\land A\Rightarrow B$                                                 | 肯定前件，推出后件             |
| 拒取式     | $(A\to B)\land\neg B\Rightarrow\neg A$                                         | 否定后件，推出否定前件         |
| 析取三段论 | $(A\lor B)\land\neg B\Rightarrow A$                                            | 否定一个支项，保留另一个       |
| 假言三段论 | $(A\to B)\land(B\to C)\Rightarrow(A\to C)$                                     | 蕴涵链传递                     |
| 等价三段论 | $(A\leftrightarrow B)\land(B\leftrightarrow C)\Rightarrow(A\leftrightarrow C)$ | 等价关系传递                   |
| 构造性二难 | $(A\to B)\land(C\to D)\land(A\lor C)\Rightarrow(B\lor D)$                      | 前件至少一个真，后件至少一个真 |
| 破坏性二难 | $(A\to B)\land(C\to D)\land(\neg B\lor\neg D)\Rightarrow(\neg A\lor\neg C)$    | 后件至少一个假，前件至少一个假 |

构造性二难的特殊形式：

$$
(A\to B)\land(\neg A\to B)\Rightarrow B.
$$

此外，每个等值式都可以双向产生两条推理定律。例如：

$$
A\Leftrightarrow\neg\neg A
$$

可产生 $A\Rightarrow\neg\neg A$ 和 $\neg\neg A\Rightarrow A$。

## 5. 自然推理系统 P
### 本章路线

根据目标主联结词选择直接证明、附加前提法或归谬法，逐行写出公式、行号和规则。

> 本章要解决的问题：怎样把多步推理拆成有限条可审查的合法步骤，而不把“看起来合理”当作规则？
>
> 本章学完应会：能完成系统 $P$ 的规范证明，并能检查前提引入、等值置换和量词以外的命题规则是否被正确使用。


### 5.1 形式系统

一个形式系统 $I$ 由四部分组成：

$$
I=\langle A(I),E(I),AX(I),R(I)\rangle,
$$

其中：

- $A(I)$：非空字母表；
- $E(I)$：由字母表中的符号构成的合式公式集；
- $AX(I)$：公理集；
- $R(I)$：推理规则集。

$\langle A(I),E(I)\rangle$ 是形式语言系统，$\langle AX(I),R(I)\rangle$ 是形式演算系统。

- 自然推理系统没有公理集，即 $AX(I)=\varnothing$；
- 公理推理系统有公理集，由系统推出的重言式称为定理。


### 5.2 系统 P 的组成

1. 字母表：命题变项、联结词 $\neg,\land,\lor,\to,\leftrightarrow$、括号和逗号；
2. 合式公式；
3. 推理规则。


### 5.3 系统 P 的推理规则

除前提引入、结论引入和置换规则外，应重点掌握：

| 规则       | 推演形式                                                           |
| ---------- | ------------------------------------------------------------------ |
| 假言推理   | $A\to B,\ A\ \therefore B$                                       |
| 附加       | $A\ \therefore A\lor B$                                          |
| 化简       | $A\land B\ \therefore A$（或 $B$）                             |
| 拒取式     | $A\to B,\ \neg B\ \therefore\neg A$                              |
| 假言三段论 | $A\to B,\ B\to C\ \therefore A\to C$                             |
| 析取三段论 | $A\lor B,\ \neg B\ \therefore A$                                 |
| 构造性二难 | $A\to B,\ C\to D,\ A\lor C\ \therefore B\lor D$                  |
| 破坏性二难 | $A\to B,\ C\to D,\ \neg B\lor\neg D\ \therefore\neg A\lor\neg C$ |
| 合取引入   | $A,\ B\ \therefore A\land B$                                     |

## 6. 在系统 P 中构造证明
### 本章路线

根据目标主联结词选择直接证明、附加前提法或归谬法，逐行写出公式、行号和规则。

> 本章要解决的问题：怎样把多步推理拆成有限条可审查的合法步骤，而不把“看起来合理”当作规则？
>
> 本章学完应会：能完成系统 $P$ 的规范证明，并能检查前提引入、等值置换和量词以外的命题规则是否被正确使用。


一个证明是公式序列 $C_1,C_2,\ldots,C_l$。每个 $C_i$ 必须是某个前提，或由前面的公式通过合法规则得到，并且最后一式 $C_l$ 必须是目标结论。

书写时建议每行包含：**序号、公式、依据的行号、规则名**。

### 6.1 直接证明法

直接从前提出发，逐步推出结论。

例：

前提：$(p\lor q)\to r,\ r\to s,\ \neg s$
结论：$\neg p\land\neg q$

证明：

| 步骤 | 公式                  | 理由               |
| ---- | --------------------- | ------------------ |
| 1    | $r\to s$            | 前提引入           |
| 2    | $\neg s$            | 前提引入           |
| 3    | $\neg r$            | 1、2 拒取式        |
| 4    | $(p\lor q)\to r$    | 前提引入           |
| 5    | $\neg(p\lor q)$     | 4、3 拒取式        |
| 6    | $\neg p\land\neg q$ | 5 置换（德摩根律） |


### 6.2 附加前提证明法

适用于结论是蕴涵式 $B\to C$ 的情况。把 $B$ 作为附加前提，只需推出 $C$：

$$
(A_1\land\cdots\land A_k)\to(B\to C)
\Leftrightarrow
(A_1\land\cdots\land A_k\land B)\to C.
$$

例：

前提：$p\lor q,\ p\to r,\ r\to\neg s$
结论：$s\to q$

| 步骤 | 公式           | 理由            |
| ---- | -------------- | --------------- |
| 1    | $s$          | 附加前提引入    |
| 2    | $p\to r$     | 前提引入        |
| 3    | $r\to\neg s$ | 前提引入        |
| 4    | $p\to\neg s$ | 2、3 假言三段论 |
| 5    | $\neg p$     | 4、1 拒取式     |
| 6    | $p\lor q$    | 前提引入        |
| 7    | $q$          | 6、5 析取三段论 |

因此 $s\to q$ 得证。


### 6.3 归谬法（反证法）

要从 $A_1,\ldots,A_k$ 证明 $B$，加入 $\neg B$ 作为临时前提；若能推出矛盾 $0$，则 $B$ 成立：

$$
A_1\land\cdots\land A_k\land\neg B\to 0.
$$

例：

前提：$\neg(p\land q)\lor r,\ r\to s,\ \neg s,\ p$
结论：$\neg q$

| 步骤 | 公式                     | 理由            |
| ---- | ------------------------ | --------------- |
| 1    | $q$                    | 结论否定引入    |
| 2    | $r\to s$               | 前提引入        |
| 3    | $\neg s$               | 前提引入        |
| 4    | $\neg r$               | 2、3 拒取式     |
| 5    | $\neg(p\land q)\lor r$ | 前提引入        |
| 6    | $\neg(p\land q)$       | 5、4 析取三段论 |
| 7    | $\neg p\lor\neg q$     | 6 置换          |
| 8    | $\neg p$               | 7、1 析取三段论 |
| 9    | $p$                    | 前提引入        |
| 10   | $\neg p\land p=0$      | 8、9 合取引入   |

矛盾产生，因此 $\neg q$ 得证。

## 7. 证明策略速查

1. **先看结论外形**：结论是 $B\to C$，优先考虑附加前提证明法；目标不易直接得到时考虑归谬法。
2. **从前提找触发点**：看到 $A\to B$，就寻找 $A$ 或 $\neg B$。
3. **从结论倒推需求**：目标是 $X\land Y$，分别设法得到 $X,Y$；目标是 $X\lor Y$，得到一个支项后可用附加律。
4. **及时做等值置换**：如 $\neg(A\lor B)\Leftrightarrow\neg A\land\neg B$。
5. **每一步都写依据**：不能凭直觉跨步。

## 8. 易错点

- 把“肯定后件”误当作假言推理：$(A\to B),B\not\Rightarrow A$。
- 把“否定前件”误当作拒取式：$(A\to B),\neg A\not\Rightarrow\neg B$。
- 忘记有效推理只排除“前提全真、结论假”的情况。
- 使用附加前提证明法时，附加的是目标蕴涵式的前件。
- 使用归谬法时，应引入目标结论的否定，并明确最终矛盾。
- 证明中引用尚未出现的公式，或省略规则与行号。

## 9. 新版课件练习梳理

### 练习 1（1）：判断有效性

前提：$\neg p\to q,\ \neg q$
结论：$\neg p$

该推理无效。取 $p=1,q=0$：$\neg p\to q=1$，$\neg q=1$，但 $\neg p=0$。这是一组成假赋值。


### 练习 1（2）：构造证明

前提：$q\to r,\ p\to\neg r$
结论：$q\to\neg p$

结论是蕴涵式，使用附加前提证明法：

| 步骤 | 公式           | 理由          |
| ---- | -------------- | ------------- |
| 1    | $q$          | 附加前提引入  |
| 2    | $q\to r$     | 前提引入      |
| 3    | $r$          | 1、2 假言推理 |
| 4    | $p\to\neg r$ | 前提引入      |
| 5    | $\neg p$     | 4、3 拒取式   |

因此 $q\to\neg p$ 得证。


### 练习 2：实际推理

前提：$p\to(q\lor r),\ s\to\neg q,\ p,\ s$
结论：$r\lor t$

推导主线：

$$
p\Rightarrow q\lor r,\qquad
s\Rightarrow\neg q,\qquad
(q\lor r)\land\neg q\Rightarrow r,\qquad
r\Rightarrow r\lor t.
$$

## 九、自测参考答案

1. $p\to q,p\therefore q$ 有效，对应 $((p\to q)\land p)\to q$ 为重言式。
2. $p\to q,q\therefore p$ 无效，反例为 $p=0,q=1$；$p\to q,\neg q\therefore\neg p$ 有效。
3. 证明 $q\to\neg p$ 的关键链为附加 $q$、得到 $r$、由拒取式得到 $\neg p$，再撤销附加前提。
