## 14.1 用状态图表达时序规格

### 本章路线

**先确定题目对象与约定 → 再写出结构、方程或状态 → 再处理极性、位序、延迟和边界 → 最后用独立检查验证。**

> 本章要解决的问题：如何把本节对象转成可计算、可实现、可复核的逻辑行为？
>
> 本章学完应会：能按本节流程完成推导或设计，并用第二种证据检查结果。


### 学习单元

#### 核心知识

状态图把序列检测、控制流程和输出条件变成有限状态机。先定义状态的语义，例如“已经看到前缀 101”，再标注每个输入下的转移和输出。

Mealy 输出在边上，响应快但可能受输入毛刺影响；Moore 输出在状态上，通常更稳定但可能多一个状态或一拍延迟。

#### 判断与操作清单

- 先写清输入、输出、状态变量或编号约定；
- 每一步保留中间结果，特别检查补号、低有效端、位序和时钟边沿；
- 结果完成后至少做一次反向代入、真值表抽查、状态追踪或波形检查；
- 若有多种实现，比较门数、级数、延迟、资源和验证成本。

##### 小练习：条件、方法与结果复核

> **题源：** 《15_第14章 状态转换图与状态.pdf》第 381—415 页范围内的学习目标、学习指导和对应习题；以下为保留原方法的条件变式。

**题目：** 设计检测序列 101 的 Mealy 状态机，允许重叠检测，说明三个状态的含义。

**解析：** S0 未匹配；S1 已看到 1；S2 已看到 10。S0 输入 1 到 S1、0 留在 S0；S1 输入 0 到 S2、1 留在 S1；S2 输入 1 输出 1 并回到 S1 以保留重叠前缀，输入 0 回 S0。

## 14.3 Moore 与 Mealy 的互换

### 本章路线

**先确定题目对象与约定 → 再写出结构、方程或状态 → 再处理极性、位序、延迟和边界 → 最后用独立检查验证。**

> 本章学完应会：能按本节流程完成推导或设计，并用第二种证据检查结果。


### 学习单元

#### 核心知识

互换表示时要保持输入序列到输出序列的对应关系。

Mealy 到 Moore 常需拆分状态，使输出依赖状态；Moore 到 Mealy 可把状态输出移到进入该状态的边上，但初始拍和输出延迟必须明确。

#### 判断与操作清单

- 先写清输入、输出、状态变量或编号约定；

- 若有多种实现，比较门数、级数、延迟、资源和验证成本。

##### 小练习：条件、方法与结果复核

> **题源：** 《15_第14章 状态转换图与状态.pdf》第 381—415 页范围内的学习目标、学习指导和对应习题；以下为保留原方法的条件变式。

**题目：** 同一检测器改成 Moore 后，为什么可能多一个状态？

**解析：** 因为 Mealy 的输出依赖“当前状态+当前输入”，而 Moore 只能把“已检测到”作为一个独立状态保存，进入该状态后输出 1，所以通常会增加状态或产生一拍延迟。

**题目：** 输入序列 00110101011 用于检测 101，验证时至少指出一处部分匹配失败后的转移。

**解析：** 从 S0 读入 0 保持 S0，读入 1 到 S1，接着 0 到 S2；若随后不是 1，则按最长后缀回到 S0 或 S1，而不是跳过输入。实际输出要按所选 Mealy/Moore 定义逐拍对齐。

## 公式卡
