## 一、先解释接口和信号，再读代码：对应10.1、10.3、10.4

### 本章路线

本章要解决的问题：接口和并发关系怎样描述？本章学完应会：先认信号、类型和接口，再读完整模块，区分并发关系、声明初值与持续赋值。

### 学习单元

#### 1.1 信号是电路线上的量，类型规定其取值

VHDL是**硬件描述语言**，描述电路功能或连接，而非处理器逐行执行的指令。**信号signal**表示连接上传递的量，**类型type**规定取值与可用运算。

bit仅有'0'、'1'；单引号的位值与整数1类型不同。例：输入A、B、D，内部C=A与B，输出E=C或D，是两级连接依赖。

#### 1.2 端口说明外部连接，实体给模块命名

**端口port**是模块对外连接，方向in、out、inout分别表示输入、输出、双向。**实体entity**命名模块并声明接口；**结构体architecture**描述其内部。

begin前声明内部信号，之后写并发关系。完整两级模块：

```vhdl
entity two_gates is
  port (A, B, D : in bit;
        E       : out bit);
end two_gates;

architecture equations of two_gates is
  signal C : bit;
begin
  C <= A and B;
  E <= C or D;
end equations;
```

实体名与architecture归属保持一致；equations是结构体名。分号结束声明或语句，port最后一组端口后不加分号，右括号后加分号。

#### 1.3 赋值表示持续关系，并发不按行排队

**信号赋值**使用<=；and、or、not、xor分别表示与、或、非、异或。用括号明确分组。

**并发**指全部关系同时存在。A或B改变引发C重新求值，C或D改变引发E求值；交换两条赋值的文本顺序不改变连接。

A=1、B=D=0时C=E=0，B变1后C、E最终均1；若D恒1，E始终1。合写E <= (A and B) or D;可表示同一稳定函数，但若研究时序，仍须明确内部结构与延迟模型。

##### 小练习：从完整接口检查三处错误

> 题源：依据教材10.1、10.3的两门模块自编，非教材原题。

**题目：** 有人把C声明为外部out端口，又在结构体中写signal C : bit;；把E <= C or D;写在C赋值前，并认为必须交换顺序；还把A的输入写成整数1。逐条说明应怎样处理，并对A=1、B=1、D=0求C、E。

**解析：** C在本题原接口中是内部线，应只在内部声明；若要把它改成外部端口，接口及内部使用规则也需重新设计，不能重复定义。两条并发赋值的文本次序不影响稳定逻辑，所以不必靠换行次序修正。bit输入值写'1'。代入A、B均为'1'，C='1'，再与D='0'相或得E='1'。接口、类型与文本顺序是三类问题，不能用同一次换行操作全部解决。

#### 1.4 名字、常量与声明初值

基本标识符以字母开头，可含数字和下划线，不以下划线结尾或连续使用下划线，大小写不敏感；data_3合法，3data、data_非法。--开始行内注释。

**constant常量**定义后不变，如constant delay1 : time := 5 ns;。time表示时间类型；integer表示整数。:=在声明中给初值，<=给信号关系。

signal A : bit := '1';只规定仿真起点，不持续强制A为1，也不自动保证硬件上电状态。bit未显式初始化时默认为'0'；例题仍应给出所需初态。

### 本章小结

实体定义接口，结构体定义内部关系；并发顺序由连接依赖决定，声明初值不等于持续赋值。

### 本章练习与检验

> 题源：教材习题10.2的四条并发关系，按原式整理并增加自编测试输入。

**题目：** F<=E and I;，I<=G or H;，G<=A and B;，H<=(not C) and D;。输入为A、B、C、D、E，输出F，中间I、G、H均为bit。给出依赖顺序和一条合并表达式。计算11011与11111两组ABCDE输入。

**解析：** G由A、B决定，H由C、D决定，I由G、H决定，F由I、E决定。合写为F <= E and ((A and B) or ((not C) and D));。11011表示A=1、B=1、C=0、D=1、E=1，G=1、H=1、I=1、F=1；11111时G=1、H=0、I=1、F=1。若只用这两组测试不能发现H错误，因为G始终屏蔽H；再取A=B=0、C=0、D=E=1，才得到G=0、H=1、I=1、F=1，能独立检验H支路。

## 二、把“如果选这路”写清楚：对应10.2

### 本章路线

本章要解决的问题：条件选择怎样完整表达？本章学完应会：先读2选1条件赋值，再区分优先选择和按编码选择，补齐其余分支。

### 学习单元

#### 2.1 条件赋值的每个分支都在送数据

**条件信号赋值**把数据放在when前，条件放在when后，else给其他情况：

```vhdl
Y <= I0 when S = '0' else I1;
```

S为bit时，0选I0、1选I1。数据与Y类型、长度须匹配，条件是boolean表达式；=是比较，<=是赋值。

I0=1、I1=0时得到not S；I0=I1=1时输出恒1。本章组合选择保留最后else，明确所有输入的输出。

#### 2.2 条件先后决定优先级

多个条件从前向后匹配：

```vhdl
F <= A when E = '1'
     else B when D = '1'
     else C;
```

E=1时选A，否则D=1时选B，否则选C。ED=11时A优先；交换前两条件会在该组合改变选择。

A=0011、B=1010、C=0101时，ED按00、01、10、11得到0101、1010、0011、0011。优先是表达式规则，不是并发语句逐行排队。

##### 小练习：交换两条条件究竟改变哪种输入

> 题源：教材习题10.3(a)的两级MUX条件表达，补充自编数据与比较。

**题目：** F<=A when D='1' else B when E='1' else C;。A=1、B=0、C=1。求DE四种组合；再与先检查E的版本比较，指出只测D≠E为什么不足。

**解析：** 原式DE=00、01、10、11分别输出1、0、1、1。先E版本00、01、10、11分别为1、0、1、0，只在11不同。D≠E只覆盖01、10，恰好无法观察优先冲突，所以不能证明优先顺序正确。若选A=B相同数据，即使测试11也看不出错误，应给两路不同测试值。

#### 2.3 连接符把选择位合成一个编号

**连接符&**按左到右拼接，A='1'、B='0'时A & B为"10"。单引号是位，双引号是位串；连接不作加法。

**选择信号赋值**用with ... select按编码选数据。sel为两位bit_vector，I0—I3、F为bit：

```vhdl
sel <= A & B;
with sel select
  F <= I0 when "00",
       I1 when "01",
       I2 when "10",
       I3 when "11";
```

A为高位；交换连接次序会互换01与10。各选择值不得重叠，逗号分隔分支，末尾分号结束整条赋值。

#### 2.4 others必须回到选择类型解释

**others**覆盖尚未列出的所有选择值。例如sel为三位bit_vector：

```vhdl
with sel select
  F <= I0 when "000",
       I7 when "111",
       '0' when others;
```

其余六种编码均输出0。若改为含X、Z的标准逻辑类型，即使列全二进制编码也未覆盖全部可能值，须重新安排others。

### 本章小结

when/else按条件优先选择；with/select按互斥选择值匹配；分支须覆盖选择类型的全部取值。

### 本章练习与检验

> 题源：依据教材10.2的三种4选1模型自编，非教材原题。

**题目：** A、B为bit，I0=0、I1=1、I2=0、I3=1。有人把选择信号写成B & A，却仍按00、01、10、11接I0—I3。求AB=01、10的输出，与正确方案比较，再给出能发现“最后两路互换”的数据配置。

**解析：** 正确01选I1=1，10选I2=0。反接后01变选择10得0，10变选择01得1，两组均发现位序错误。当前I2=0、I3=1也能区分最后两路；测试AB=10与11分别应为0、1，交换后为1、0。若I2=I3，两路互换会被相同数据掩盖，所以测试应让待区分的支路具有不同值。

## 三、一串数据怎样编号和运算：对应10.4—10.6

### 本章路线

本章要解决的问题：类型和下标怎样决定结果？本章学完应会：先明确类型，再按下标方向求元素、切片、连接和运算结果。

### 学习单元

#### 3.1 bit、boolean与integer表示不同对象

bit取'0'、'1'；**boolean**取FALSE、TRUE；**integer**取整数。A>B返回boolean，若Flag为bit，应作显式选择：

```vhdl
Flag <= '1' when A > B else '0';
```

VHDL是强类型语言，bit_vector不会自动等于整数。integer range 0 to 15限定范围，赋16不会自动模16回绕。

其他基本类型：positive为正整数，natural含0，real为实数，character为字符，time为时间。自定义**枚举类型**如type color_type is (red, green, blue);，对象只能取列出的值。

#### 3.2 数组是同类元素按下标排列

**数组array**用下标排列同类元素；bit_vector是一维bit数组。对signal A : bit_vector(3 downto 0);，字符串"1010"按声明顺序赋给A(3)—A(0)。若B范围为0 to 3，同一字符串对应B(0)—B(3)，所以A(0)=0而B(0)=1。

**切片slice**取连续范围：A(3 downto 2)="10"。A(0)是bit，A(0 downto 0)是长度1的向量，类型不同。

自定义类型先声明再使用：type word4 is array(3 downto 0) of bit; signal Data : word4;。即使元素相同，也须按各自类型规则检查兼容性。

##### 小练习：字符串相同，下标取值可以不同

> 题源：依据教材10.5的位向量与切片概念自编，非教材原题。

**题目：** A为bit_vector(5 downto 0)，B为bit_vector(0 to 5)，二者均赋"101100"。求A(5)、A(0)、A(4 downto 2)，以及B(0)、B(5)、B(1 to 3)。再求A(0) & A(5 downto 1)。

**解析：** A从下标5到0依次1、0、1、1、0、0，所以A(5)=1、A(0)=0、A(4 downto 2)="011"。B从0到5依次1、0、1、1、0、0，所以B(0)=1、B(5)=0、B(1 to 3)="011"。连接结果为'0' & "10110"，即"010110"。最后一步以当前最右位补到左端，其余位右移一个位置，但这是一条组合位重排，不涉及数据随时钟保存或移动。

#### 3.3 聚合、二维数组与无约束数组

**聚合**按声明顺序给全部元素赋值，(others => '1')给未单列的位赋1。

**二维数组**如type matrix4x3 is array(1 to 4, 1 to 3) of integer;，M(3,2)取第3行第2列；四行依次为(1,2,3)至(10,11,12)时，该元素为8。

**无约束数组类型**暂不限定长度：type intvec is array(natural range <>) of integer;。对象仍须定范围，如signal V : intvec(1 to 5) := (3,2,6,8,1);，声明后不能任意变长。

string是字符数组，bit_vector是位数组；同一文字"1010"的类型由上下文决定。

#### 3.4 逐位逻辑、关系与括号

等长位向量的逻辑运算逐位进行：A="1100"、B="1010"时，A and B="1000"，A xor B="0110"。

关系运算=、/=、<、<=、>、>=返回boolean。C <= (A <= B);中，外层<=是信号赋值，括号内<=是比较，C须为boolean。

优先级不要照搬普通布尔代数：not先于连接&，连接先于逻辑层；教材中and、or、xor等同属逻辑层，混用应明确括号。例如F <= (A and B) or ((not C) and D);。每个中间向量仍须核对类型和长度。

##### 小练习：先算中间组，再检查每一步长度

> 题源：依据教材10.6的连接与逻辑运算自编，非教材原题。

**题目：** A="1010"、B="0110"均为4位，C="10"为2位。求F <= ((not A) and B) or (C & "01");。逐步列出中间值与长度，并判断把C改成3位"010"后是否还能保持原式。

**解析：** not A="0101"，与B得到"0100"，均4位。C & "01"为"1001"，长度2+2=4。最终"0100" or "1001"="1101"。若C改3位，连接结果5位，与左边4位逐位或不匹配；即使最后输出F也改成5位，左支仍只有4位，所以不能只扩输出掩盖内部长度问题。

#### 3.5 组合移位是重新安排位的位置

教材运算符sll/srl为逻辑左/右移，sla/sra为算术左/右移，rol/ror为循环左/右移。这里是对当前向量重新排列，不自动构成移位寄存器。

对A="10010101"：

| 运算 | 补位或回绕规则 | 结果 |
| --- | --- | --- |
| sll 2 | 右补0 | 01010100 |
| srl 3 | 左补0 | 00010010 |
| sra 2 | 复制左端1 | 11100101 |
| rol 3 / ror 5 | 移出位绕回 | 10101100 |

教材sla复制右端位，不是一律补0。切片连接可明确补位："00" & A(7 downto 2)为00100101；A(7) & A(7) & A(7 downto 2)为11100101。

### 本章小结

类型决定可用操作，下标方向决定位序，逻辑与连接须检查长度，移位须明确补位规则。

### 本章练习与检验

> 题源：依据教材10.5—10.6的数组、切片与移位概念自编，非教材原题。

**题目：** A为bit_vector(7 downto 0)，值为"11001010"。组合输出L为逻辑左移两位，R为补符号位右移三位，T为左右四位互换。用切片与连接表示，并写出结果；说明这些描述是否自己保存了上一次A。

**解析：** L <= A(5 downto 0) & "00";得到"00101000"。R <= A(7) & A(7) & A(7) & A(7 downto 3);得到"11111001"。T <= A(3 downto 0) & A(7 downto 4);得到"10101100"。长度分别为6+2、3+5、4+4，均8位。三式只由当前A决定，没有独立保存上次A的功能；输入变后，输出按新的位组合重新求值。

## 四、把完整小模块连接成较大电路：对应10.3、10.5

### 本章路线

本章要解决的问题：小模块怎样组成大电路？本章学完应会：完整描述全加器，再实例化组成四位加法器，最后用常量数组查表。

### 学习单元

#### 4.1 先把一个全加器描述完整

全加器输入X、Y、Cin，输出Cout、Sum；Sum为三位异或，Cout在至少两输入为1时置1。完整模块：

```vhdl
entity FullAdder is
  port (X, Y, Cin : in bit;
        Cout, Sum : out bit);
end FullAdder;

architecture equations of FullAdder is
begin
  Sum  <= (X xor Y) xor Cin;
  Cout <= (X and Y) or (X and Cin) or (Y and Cin);
end equations;
```

Cout排在Sum前是接口顺序，不是执行先后。输入101时，Sum=0，Cout=1，对应1+0+1=2，即两位10。

#### 4.2 元件声明与实例是两件事

**component元件声明**给接口，**instance实例**是一份实际模块连接。**port map端口映射**采用位置时按声明次序对应。

FullAdder端口顺序为X、Y、Cin、Cout、Sum，因此(A(0), B(0), Ci, C(1), S(0))把C(1)接进位。交换最后两根线可能仍通过类型检查，却接错功能。

四位上层模块如下，与前述FullAdder共同使用；C为内部进位线：

```vhdl
entity Adder4 is
  port (A, B : in bit_vector(3 downto 0);
        Ci   : in bit;
        S    : out bit_vector(3 downto 0);
        Co   : out bit);
end Adder4;

architecture structure of Adder4 is
  component FullAdder
    port (X, Y, Cin : in bit; Cout, Sum : out bit);
  end component;
  signal C : bit_vector(3 downto 1);
begin
  FA0 : FullAdder port map(A(0), B(0), Ci,   C(1), S(0));
  FA1 : FullAdder port map(A(1), B(1), C(1), C(2), S(1));
  FA2 : FullAdder port map(A(2), B(2), C(2), C(3), S(2));
  FA3 : FullAdder port map(A(3), B(3), C(3), Co,   S(3));
end structure;
```

四个实例同时存在，进位传播方向由C(1)—C(3)的连接决定，不由实例书写顺序决定。

##### 小练习：沿进位线核对一个有溢出的和

> 题源：依据教材10.3四位加法器结构自编，非教材原题。

**题目：** A=1011、B=0110、Ci=1。逐位写出每个实例的输入、和位与输出进位，最终给出Co与S，再解释只观察S会丢掉什么。

**解析：** 最低位1+0+1=2，S0=0、C1=1；第1位1+1+1=3，S1=1、C2=1；第2位0+1+1=2，S2=0、C3=1；第3位1+0+1=2，S3=0、Co=1。结果CoS=10010，即18，S单独为0010。只看S保留了低4位，未保留16这一位，不能据此声称11+6+1=2。

#### 4.3 用常量数组给组合函数查表

常量数组可保存真值表。先用整数地址，避免引入未教的类型转换：

```vhdl
entity double_table is
  port (addr : in integer range 0 to 3;
        Y    : out bit_vector(2 downto 0));
end double_table;

architecture lookup of double_table is
  type table_type is array(0 to 3) of bit_vector(2 downto 0);
  constant table_data : table_type := ("000", "010", "100", "110");
begin
  Y <= table_data(addr);
end lookup;
```

addr=2读数组第三字"100"。外层下标选字，内层向量表示字宽；bit_vector地址须先按明确规则转换为整数，不能直接当下标。

### 本章小结

元件声明只是接口，实例及port map才形成实际连接；常量数组按地址选完整数据字。

### 本章练习与检验

> 题源：依据教材10.3、10.5的结构描述与数组表自编，非教材原题。

**题目：** 两位无符号数A、B相加且无输入进位。若用ROM数组查表，地址按A1A0B1B0编号，需要多少字和几位输出？列出地址0000、0111、1111的字，并与两级全加器结果比较。

**解析：** 四个地址位共有16字，最大3+3=6需3位输出。0000为0+0，存000；0111为1+3，存100；1111为3+3，存110。以0111为例，最低位1+1=2得S0=0、进位1，高位0+1+1=2得S1=0、最高进位1，拼成100，与查表一致。数组表是一次按地址取字，门级实现是两级加法连接；它们稳定功能相同，但未指定延迟前不能直接比较到达时间。

## 五、使用包、标准逻辑和教材算术：对应10.7—10.8

### 本章路线

本章要解决的问题：类型、驱动和算术怎样匹配？本章学完应会：先用包取得声明，再区分标准逻辑、多驱动与无符号算术，核对结果位宽。

### 学习单元

#### 5.1 包收集声明，库保存可引用的设计内容

**package包**收集可复用的类型、常量和元件声明；需要实现时另有package body。**library库**组织已分析的设计单元，use让包内名字在当前单元可见。

教材library BITLIB; use BITLIB.bit_pack.all;引用教材门元件包；all表示全部可见声明，仍须本机具备已编译的库。

教材vec2int函数来自bit_pack，将位向量变成整数地址：A & B & C为101时，转换成5，读八行表的第六行。它不是bit_vector自带运算，也不属于std_logic_1164。增加地址位还须扩大表范围。

#### 5.2 std_logic让未知和退出驱动有自己的值

**std_logic**是含九种值的标准逻辑类型，本章重点：U未初始化、X不确定/冲突、0和1为确定逻辑、Z高阻。std_logic_vector是其向量。

```vhdl
library ieee;
use ieee.std_logic_1164.all;
```

该包提供类型和逻辑运算，不自动提供全部向量算术。

三态片段Y <= A when En = '1' else 'Z';在关闭时退出驱动；4位向量则使用"ZZZZ"。U与X不能随意改成0来掩盖起点或驱动问题。

#### 5.3 多条赋值表示多个驱动，不会自动形成优先

对同一std_logic_vector的两条并发赋值表示**两个驱动源**：

```vhdl
F <= A when EA = '1' else "ZZZZ";
F <= B when EB = '1' else "ZZZZ";
```

解析规则逐位合并驱动值。A=1010、B=1001时：仅EA=1得1010；全关得ZZZZ；全开得10XX。

文本先后不构成优先级。若要EA优先，应写一条完整when/else关系。bit无相同多源解析规则；模型能表达多驱动也不表示硬件任意接线都合法。

##### 小练习：用一组数据区分优先选择与总线合并

> 题源：依据教材10.8图10-17的双三态驱动自编，非教材原题。

**题目：** A="0011"、B="0101"。先按上面双驱动代码求EAEB=10、01、00、11；再改成EA优先、EB次优先、空闲输出0000的单条条件赋值。哪两种控制组合的结果发生变化？

**解析：** 双驱动依次为0011、0101、ZZZZ、0XX1。单条选择可写F <= A when EA='1' else B when EB='1' else "0000";，结果依次0011、0101、0000、0011。变化发生在00和11：前者由退出变成主动零，后者由冲突变成确定选A。两种代码表达不同电路约定，不能说它们只是书写风格不同。

#### 5.4 运算重载与无符号解释

**运算重载**让同名运算符对不同类型有相应定义。教材用use ieee.std_logic_unsigned.all;将std_logic_vector按无符号数解释；仍需std_logic_1164定义类型，且工具须提供教材所用包。

要保留4位加法的进位，**先扩位，再相加**。A=1011、B=0110时，11+6=17：

```vhdl
Addout <= ('0' & A) + ('0' & B);
Sum    <= Addout(3 downto 0);
Cout   <= Addout(4);
```

01011+00110=10001，故Sum=0001、Cout=1。先作4位运算再扩宽，不能恢复已丢进位；加入Cin也应在扩展后的宽度内计算。

##### 小练习：先扩位和后扩位为什么不同

> 题源：依据教材10.8图10-19的保留进位方法自编，非教材原题。

**题目：** 两个4位无符号数A=1110、B=0101。方案甲先保留4位和S4，再将其左补0得到5位；方案乙先给A、B各左补0，再做5位加法。求两结果，并与整数计算核对。

**解析：** 整数14+5=19，完整二进制10011。甲的4位和只留0011，后补0得到00011，数值3；乙扩成01110与00101，相加10011，数值19。差值16正是被甲丢掉的第五位。赋值目标更宽不自动证明中间表达式也以更宽精度计算，应明确扩展操作数。

### 本章小结

类型包与算术包职责不同；多条赋值是多驱动，先扩位再加法才能保留进位。

### 本章练习与检验

> 题源：依据教材10.7—10.8的库、逻辑类型及算术方法自编，非教材原题。

**题目：** 一个设计有4位输入A、B及5位输出Y，要输出完整无符号和；同时一个高有效En决定Y是否驱动外部5位总线，关闭时全高阻。给出所需声明来源和组合片段，测试A=1111、B=0001的两种En。

**解析：** 类型来自ieee.std_logic_1164，向量算术按教材来自ieee.std_logic_unsigned。声明内部5位Addout，先Addout <= ('0' & A) + ('0' & B);，再Y <= Addout when En='1' else "ZZZZZ";。15+1=16，Addout=10000，En=1时输出10000，En=0时ZZZZZ。若将关闭输出写00000，表示主动驱动0；若不扩位相加，开放时也可能只得到截断结果，两类错误须独立检查。

## 六、信号何时更新：对应10.1、10.9

### 本章路线

本章要解决的问题：信号何时更新，如何验证？本章学完应会：沿事件依赖区分执行和更新，再比较delta、惯性和传输模型，明确工具各阶段的证据。

### 学习单元

#### 6.1 先看两个门各延迟五纳秒

**事件**是信号值改变；**执行**是重新计算右侧，**更新**是结果实际到达左侧。after给出从执行到结果到达的延迟。

C <= A and B after 5 ns;，E <= C or D after 5 ns;。初态A=1、B=D=C=E=0且稳定，0ns时B变1：

| 物理时刻 | 刚发生的改变 | 下一项安排 |
| --- | --- | --- |
| 0 ns | B由0变1 | C在5 ns变1 |
| 5 ns | C由0变1 | E在10 ns变1 |
| 10 ns | E由0变1 | 没有新的后级关系需要传播 |

若D恒1，E原已为1，C变化虽引发求值却没有新E事件。

#### 6.2 没写after时，先用例子再解释delta

去掉上述after，1ns时B从0变1，仍须按依赖分轮更新：

| 物理时刻与轮次 | B、C、E | 当前含义 |
| --- | --- | --- |
| 1 ns，第0轮 | 1、0、0 | 外部B事件到来 |
| 1 ns，第1轮 | 1、1、0 | C更新引发E重新计算 |
| 1 ns，第2轮 | 1、1、1 | E更新，当前时刻稳定 |

**delta周期**是零物理时间的更新轮次，教材写1+Δ、1+2Δ，物理时刻仍为1ns。当前时刻传播稳定后，时间才前进。

例如B<=not A;、C<=not B;、D<=not C after 5 ns;，初态A=0、B=1、C=0、D=1，3ns令A变1：同一3ns内B先变0、C再变1，D在8ns变0，不将两轮delta计成2ns。

##### 小练习：两支同时改变，轮次不等于行数

> 题源：依据教材10.1图10-3与10.9图10-22自编，非教材原题。

**题目：** B<=not A;，C<=A and X;，E<=B or C;。开始A=0、X=1、B=1、C=0、E=1，4 ns时A变1。写第一轮和第二轮值，判断E最终是否有事件。

**解析：** A改变使B、C两式同时重新计算，第一轮B=0、C=1。E由它们的新值重新计算为0 or 1=1，仍是原值，第二轮没有实际E数值变化。不能因为经过两级就自动画E脉冲，也不能按文本先改B、后改C而在同一模型中凭空制造一个可见低电平。这里两条上游关系采用相同零延迟轮次，若另加不同物理延迟则需重新列事件。

#### 6.3 惯性延迟先看短脉冲是否留下输出

教材默认after赋值采用**惯性延迟**，过滤过短变化。设C<=A and B after 10 ns;，B恒1，开始A=1、C=0，初始化安排C在10ns变1。

A在15ns变0、30ns变1、35ns再变0：15—30ns低电平持续15ns，使C在25ns变0；30—35ns高脉冲仅5ns，小于10ns，被过滤，C之后保持0。

本例避开脉宽恰好等于阈值的边界，临界情况按具体语义判断。

#### 6.4 传输延迟把每个脉冲整体后移

改为C <= transport A and B after 10 ns;，沿用相同输入，**传输模型**保留每个脉冲：C在10、25、40、45ns依次为1、0、1、0，40—45ns的高脉冲仍宽5ns。

两模型延迟均10ns，区别在短变化是否传播。验证应包含短脉冲；只测长转换无法区分。after描述仿真时间，不保证综合出精确指定延迟的硬件。

#### 6.5 编译、加工、仿真与综合各自验证什么

| 阶段 | 实际检查什么 | 不能替代什么 |
| --- | --- | --- |
| 编译/分析 | 语法、类型、引用 | 功能是否接对 |
| 加工 elaboration | 实例及连接能否建立 | 输出是否符合规格 |
| 仿真 | 给定输入和模型下的响应 | 全部情况与真实硬件 |
| 综合 | 描述能否映射为逻辑 | 实测功能与时序 |

四位加法器至少测无进位、内部进位传播、最高位进位和Cin输入，并等待模型传播完成。若四级各10ns，5ns就读取不能当作稳定答案。

### 本章小结

语句执行是求值，信号更新是结果到达；延迟模型、delta轮次和工具验证阶段分别判断。

### 本章练习与检验

> 题源：依据教材10.1延迟与10.9事件安排自编，非教材原题。

**题目：** 输入A开始0，B<=not A;，C<=not B after 4 ns;。模型已在0 ns之前稳定，A在10 ns变1、12 ns变0、20 ns变1。分别按默认惯性和transport求C事件，且注明B的delta更新位置。

**解析：** 稳定初始B=1、C=0。A的三次改变后，B分别在10、12、20 ns的下一delta轮次变0、1、0。默认惯性下，10—12 ns的高目标只持续2 ns，小于4 ns，因此C不在14 ns变1；20 ns的目标1持续，C在24 ns变1。transport则在14 ns变1、16 ns变0、24 ns变1。B的delta不应加成一个整数ns，所以不能把这些时刻写成15、17、25 ns。

## 本章综合习题测验

先独立作答，再核对解析。

> 题源：依《逻辑设计基础》第7版本章10.1—10.9节已讲内容自编综合题，所给数据与题目组合不冒充教材原题。

### 第1题：从组合规格写完整模块

**题目：** 输入A、B、S及输出Y均为bit，要求S=0时Y=A与B，S=1时Y=A异或B。写完整entity与architecture，计算ABS=110、111、011。解释把该并发赋值写在其他并发语句前后是否会产生优先级。

**解析与答案：** 可直接用已学条件信号赋值：

```vhdl
entity choose_logic is
  port(A, B, S : in bit; Y : out bit);
end choose_logic;

architecture equations of choose_logic is
begin
  Y <= (A and B) when S = '0' else (A xor B);
end equations;
```

110取与，Y=1；111取异或，Y=0；011取0异或1，Y=1。entity给端口，architecture给内部关系；条件分支由S选择。各并发关系同时存在，源代码排列不额外赋予执行优先级，功能仍需按条件与连接核对。

### 第2题：数组范围、切片与连接

**题目：** A为bit_vector(5 downto 0)，值为"101001"。求A(4 downto 1)、A(0) & A(5 downto 1)的内容与位宽；若输出目标只有五位，能否直接接收后一表达式？解释这里的连接与普通整数加法有何区别。

**解析与答案：** 索引5到0对应1、0、1、0、0、1。A(4 downto 1)依次取0、1、0、0，得"0100"，四位；A(0)为1，与五位切片"10100"连接，得"110100"，六位。

五位目标与六位表达式不匹配，应先按功能决定需保留哪些位并显式选择，不能假定自动丢弃最高位。&按操作数的顺序拼接位串，不执行整数相加；各位置的数值含义还取决于声明的索引和具体用途。

### 第3题：逐级加法与输出位宽

**题目：** 四位全加器链计算A=1111、B=0011、Ci=0。从低位到高位写和位与进位，给出S、Co。若教材算术包中的向量加法先在四位完成再给结果左接'0'，能否恢复进位？说明应在什么位置扩位。

**解析与答案：** 第0位1+1+0=2，S0=0、C1=1；第1位1+1+1=3，S1=1、C2=1；第2位1+0+1=2，S2=0、C3=1；第3位同样得S3=0、Co=1。故S="0010"，完整CoS="10010"，即18。

若四位结果已截为0010，再接'0'只得到00010，无法找回已丢进位。应先把两输入各左接0扩为五位，再按正文所用算术包相加，保留五位结果。类型声明、所用包与扩位位置都需明确；位宽正确不自动证明端口连接也正确。

### 第4题：端口映射正确还要看端口含义

**题目：** 全加器端口顺序为X、Y、Cin、Cout、Sum。上层本应写port map(A(0), B(0), Ci, C(1), S(0))，却将最后两项互换。取A(0)=1、B(0)=0、Ci=1，求错误线路C(1)、S(0)的值，说明为什么相同bit类型未必能发现此错误。

**解析与答案：** 全加器实际应输出Cout=1、Sum=0。若映射写成最后两项S(0)、C(1)，就让S(0)接到Cout而变1，C(1)接到Sum而变0，最低和位与向高位传的进位同时接错。

端口位置映射按声明次序逐项对应，两个输出都是bit，类型层面允许这样的连接，却不知道哪一根线应承担进位的功能。上层应恢复原顺序，再用向高位传播的输入复核整个加法链；只检查全部输入为0可能看不出接反。

### 第5题：信号事件与两种延迟模型

**题目：** 已稳定A=0、Y=0，关系为Y <= transport A after 6 ns;。A在8 ns变1、10 ns变0、20 ns变1并保持。求Y全部事件；若删去transport使用默认惯性，结果怎样？若A的变化先经过一个无after的组合信号，再进入此关系，是否应自动加1 ns？

**解析与答案：** 理想传输把每次变化延后6 ns，Y在14 ns变1、16 ns变0、26 ns变1。默认惯性会拒绝8—10 ns这个仅持续2 ns的高目标，Y不在14 ns升高，保持0直到26 ns升1。

无after的组合信号需要仿真中的信号更新轮次，使依赖关系稳定，但该轮次不等于1 ns的物理延迟；本题没有给额外整数时间，不能把14、16、26改写成15、17、27。应分别记录同一时刻的更新先后和有明确after的时间推进。

## 公式卡

并发组合关系对应稳定函数：

$$
C=AB,\qquad E=C+D.
$$

2选1代码为Y <= I0 when S='0' else I1;，完整覆盖bit选择；条件链第一个满足条件的分支优先，with ... select以互斥选择值覆盖输入。

数组长度为下标位置数，连接后长度为各段长度之和；逐位二元逻辑的各操作数须满足对应类型与长度。位值用单引号，位串用双引号，判断表达式结果为boolean。

保留无符号进位先扩操作数：Addout <= ('0' & A)+('0' & B);。教材算术含义依赖已说明的包，标准逻辑类型声明本身不代替算术定义。

物理路径延迟按各级模型累加，delta只计同一物理时刻的更新轮次；惯性与transport对严格短于指定延迟的脉冲是否保留不同。after表示模型时间，不独立证明硬件延迟。
