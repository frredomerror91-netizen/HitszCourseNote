## 5.1 最简形式与卡诺图任务

### 本章路线

**先确定题目对象与约定 → 再写出结构、方程或状态 → 再处理极性、位序、延迟和边界 → 最后用独立检查验证。**

> 本章要解决的问题：如何把本节对象转成可计算、可实现、可复核的逻辑行为？
>
> 本章学完应会：能按本节流程完成推导或设计，并用第二种证据检查结果。


### 学习单元

#### 核心知识

把开关函数写成适合化简的形式，是从代数式进入图形法的桥梁。积之和（SOP）是若干乘积项相或；和之积（POS）是若干和项相与。

卡诺图把每个最小项放在格雷码顺序的格子中，使相邻格只改变一个变量。化简的目标不是少画几个圈，而是在不覆盖规定 0 的前提下，用尽量少的、尽量宽的圈保留必要变量。

#### 判断与操作清单

- 先写清输入、输出、状态变量或编号约定；
- 每一步保留中间结果，特别检查补号、低有效端、位序和时钟边沿；
- 结果完成后至少做一次反向代入、真值表抽查、状态追踪或波形检查；
- 若有多种实现，比较门数、级数、延迟、资源和验证成本。

##### 小练习：条件、方法与结果复核

> **题源：** 《06_第5章卡诺图.pdf》第 94—116 页范围内的学习目标、学习指导和对应习题；以下为保留原方法的条件变式。

**题目：** 对 F(A,B,C,D)=Σm(0,1,4,5,8,9,12,13) 先判断能否直接读出一个公共变量，并说明 SOP 圈组。

**解析：** 这些编号的二进制中 C 始终为 0，故八格可圈成一组，F=C′。检查时必须回代所有 1 行；若把格子按普通二进制顺序排列，会漏掉边界相邻。

### 本章小结

本节的可迁移方法是：先把卡诺图题目翻译成明确的逻辑对象，再按教材流程逐步求解，最后用独立证据检查。对于边界条件，不能用“通常如此”代替约定；应把极性、编号、时钟、位宽、复位或无关项写在答案旁边。

### 学习单元

#### 核心知识

二变量图是 2×2，三变量图通常把两列变量按 00、01、11、10 排列。圈 1 得 SOP：圈内恒为 1 的变量写原，恒为 0 的变量写补；圈 0 得 POS：圈内恒为 0 的变量写原，恒为 1 的变量写补。

圈必须是矩形，格数为 2 的幂，允许跨边界相邻。

##### 小练习：条件、方法与结果复核

> **题源：** 《06_第5章卡诺图.pdf》第 94—116 页范围内的学习目标、学习指导和对应习题；以下为保留原方法的条件变式。

**题目：** 给 F(R,S,T)=Σm(0,1,5,6)，画三变量图，至少指出一组合法圈和一个不能圈的原因。

**解析：** m0、m1 可圈成 R′S′；m1、m5 可圈成 S′T；m6 需与相邻的规定 1 或可用无关项合并，否则只能单格。m2 与 m6 虽编号差 4，但只有在图上相邻且输出同为 1 时才能圈，不能只按十进制差值判断。

#### 核心知识

四变量图为 4×4，行列都用格雷码；四角互相连通。五变量图可看成两张四变量图，额外变量取 0 和 1；两张图中同位置的格子也相邻。

画图时先标变量分组，再按最小项或最大项填值，避免把行列标签当作普通二进制顺序。

##### 小练习：条件、方法与结果复核

> **题源：** 《06_第5章卡诺图.pdf》第 94—116 页范围内的学习目标、学习指导和对应习题；以下为保留原方法的条件变式。

**题目：** 对 F(A,B,C,D)=Σm(1,3,7,9,11,15)，找出至少两种不同的合法圈法，并说明为什么 m1 与 m3 可以相邻而 m1 与 m2 不可以。

**解析：** m1=0001 与 m3=0011 只改变 C，可合并；m1 与 m2 同时改变 C、D，不能直接合并。可圈 {1,3,9,11} 得 B′D，圈 {3,7,11,15} 得 CD，因此 F=B′D+CD；两组都必须覆盖全部规定 1。

## 5.4 首要蕴含项、无关项与 NAND/NOR 读图

### 本章路线

**先确定题目对象与约定 → 再写出结构、方程或状态 → 再处理极性、位序、延迟和边界 → 最后用独立检查验证。**

### 学习单元

#### 核心知识

不能再扩大的合法圈对应首要蕴含项；只覆盖某个规定 1 的首要蕴含项是基本首要蕴含项，必须选入。无关项 X 可以在圈 1 时当作 1、圈 0 时通常避开，也可以不用。

化简后还要检查代价：SOP 适合与门—或门，POS 适合或门—与门，NAND/NOR 实现则利用德摩根定律和反相圆点重新安排极性。

#### 判断与操作清单

- 先写清输入、输出、状态变量或编号约定；

- 结果完成后至少做一次反向代入、真值表抽查、状态追踪或波形检查；
- 若有多种实现，比较门数、级数、延迟、资源和验证成本。

##### 小练习：条件、方法与结果复核

> **题源：** 《06_第5章卡诺图.pdf》第 94—116 页范围内的学习目标、学习指导和对应习题；以下为保留原方法的条件变式。

**题目：** 函数 F=Σm(0,2,8,10)+d(1,3,9,11)，比较使用无关项和不使用无关项的 SOP，并指出有效行上的等价检查范围。

**解析：** 使用 X 可把 0、2、8、10 与 1、3、9、11 合成八格，得到 B′；不使用 X 时可得到 B′D′。二者只需在规定 1 和规定 0 上比较，X 行允许不同，但不能让规定 0 变成 1。

## 自测参考答案

### 综合题参考框架

先写约定，再列中间表或方程；随后处理一个边界条件；最后用全量或代表性输入进行反向检查。若使用工具或 VHDL，应同时报告输入、版本/类型、时钟或仿真等待条件，不能只给最终截图。

### 复习核对

能解释“为什么这样做”、能指出条件改变后的影响、能用第二种表示复核结果，才算完成本章。只背结论而不能定位失败条件，不算通过。

## 公式卡

卡诺图相邻格只改变一个变量；圈 1 得 SOP，圈 0 得 POS；圈组大小为 2 的幂且允许边界相邻。
