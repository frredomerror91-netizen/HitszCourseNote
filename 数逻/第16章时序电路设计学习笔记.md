# 第 16 章 时序电路设计学习笔记

## 本章要学什么

本章依据《逻辑设计基础（第7版）》第 16 章的学习目标、学习指导和习题范围整理，主线是：**把时序电路设计中的结构、方程或操作转成可验证的数字逻辑行为**。阅读时先理解模型，再完成紧邻的条件变式，最后用章节检验检查边界。

学完后应能：

- 说清本章核心对象、输入输出、状态或时序假设，而不是只背术语；
- 按教材方法完成至少一种手算或结构化设计，并能用真值表、状态表、波形或仿真结果复核；
- 识别位序、极性、延迟、复位、无关项、未用状态等边界条件；
- 将结果映射到后续章节的门电路、触发器、算术单元或 VHDL 描述。

## 16.1 从规格到状态机

### 本章路线

**先确定题目对象与约定 → 再写出结构、方程或状态 → 再处理极性、位序、延迟和边界 → 最后用独立检查验证。**

> 本章要解决的问题：如何把本节对象转成可计算、可实现、可复核的逻辑行为？
>
> 本章学完应会：能按本节流程完成推导或设计，并用第二种证据检查结果。


### 学习单元

#### 核心知识

时序电路设计按“规格—状态图—状态表—状态化简—状态赋值—触发器方程—输出逻辑—实现验证”推进。

先定义每个状态的记忆意义，再决定 Mealy 或 Moore；过早写门电路会把规格错误隐藏在代数式里。

#### 判断与操作清单

- 先写清输入、输出、状态变量或编号约定；
- 每一步保留中间结果，特别检查补号、低有效端、位序和时钟边沿；
- 结果完成后至少做一次反向代入、真值表抽查、状态追踪或波形检查；
- 若有多种实现，比较门数、级数、延迟、资源和验证成本。

##### 小练习：条件、方法与结果复核

> **题源：** 《17_第16章日时序电路设计.pdf》第 461—492 页范围内的学习目标、学习指导和对应习题；以下为保留原方法的条件变式。

**题目：** 设计一个带使能 E 的两状态控制器：E=1 时在 RUN 与 IDLE 间切换，E=0 时保持，输出在 RUN 状态为 1。列出设计步骤。

**解析：** 先定义两状态和输出，再列转移：IDLE 在 E=1 到 RUN，RUN 在 E=1 到 IDLE，其余保持；选择编码 Q=0/1，写 Q+=Q⊕E，Z=Q，最后按触发器类型实现。

## 16.2 触发器输入方程

> 本章学完应会：能按本节流程完成推导或设计，并用第二种证据检查结果。


### 学习单元

#### 核心知识

D 触发器直接令 D=Q+；T 触发器令 T=Q⊕Q+；J-K 触发器可从激励表得到 J、K，并利用无关项化简。

每次推导后都要把方程代回特性方程，检查保持、置位、复位和翻转四类行为。

#### 判断与操作清单

- 先写清输入、输出、状态变量或编号约定；

- 若有多种实现，比较门数、级数、延迟、资源和验证成本。

##### 小练习：条件、方法与结果复核

> **题源：** 《17_第16章日时序电路设计.pdf》第 461—492 页范围内的学习目标、学习指导和对应习题；以下为保留原方法的条件变式。

**题目：** 若状态位 Q+=XQ′+Q，分别给出 D 和 T 输入。

**解析：** D=XQ′+Q；T=Q⊕Q+=Q⊕(XQ′+Q)=XQ′。当 Q=0、X=1 时翻转，当 Q=1 时保持。

## 16.3 输出逻辑与时序约束

### 学习单元

#### 核心知识

输出可由状态生成，也可由状态和输入生成。组合输出路径短而直接，但可能有输入冒险；寄存器输出更稳定但引入延迟。

时钟周期应满足触发器时序不等式，并留出组合逻辑和偏斜余量。

#### 判断与操作清单

- 先写清输入、输出、状态变量或编号约定；

##### 小练习：条件、方法与结果复核

> **题源：** 《17_第16章日时序电路设计.pdf》第 461—492 页范围内的学习目标、学习指导和对应习题；以下为保留原方法的条件变式。

**题目：** 一个 Moore 输出由 Q 解码，一个 Mealy 输出由 Q 和 X 解码，哪个更容易在异步 X 变化时产生毛刺？

**解析：** Mealy 输出直接受 X 影响，更容易出现组合毛刺；若输出必须稳定，应寄存输出或对输入同步化。

实现后要检查复位路径、未用编码、所有输入组合和状态回绕。

未用状态不能留在“无所谓”状态，除非明确保证永远不可达；安全设计通常让它们回到复位或安全状态。

**题目：** 三状态用两位编码后有一个未用码，给出处理它的两种策略和选择依据。

**解析：** 可让未用码在下一拍回到复位状态，或把它映射到安全输出并等待复位。选择取决于故障安全、面积、恢复速度和是否允许额外逻辑；必须在状态表中明确。
