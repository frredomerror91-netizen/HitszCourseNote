# HITSZ Course Note

这是一个按学科整理的课程学习笔记仓库，用于保存个人课程学习过程中的总结、讲义式笔记和复习资料。

## 仓库结构

每个学科使用一个独立文件夹：

- `数逻`
- `概率论`
- `大物学习`
- `高电学习`
- `复变学习`
- `离散学习`
- `文理通识`

每个学科文件夹只存放该学科的学习笔记及笔记正文引用的必要图片，不存放发布脚本、测试代码、配置文件、教材、PDF、实验资料、草稿或其他项目材料。

## 内容范围

本仓库只收录个人课程学习笔记。`信息安全竞赛`属于竞赛训练资料，不属于本课程学习笔记仓库，因此不在本仓库中收录，也不会被后续默认发布流程上传。

## 自动发布规则

从原学科目录生成并完成审核的学习笔记，会按本次任务的明确文件清单发布到对应学科文件夹。发布前会执行 DryRun 和路径/内容检查，避免把同目录中的其他资料一起上传。

默认发布白名单只有：

1. 本次新生成或修改、已经审核的 Markdown 学习笔记；
2. 这些笔记正文实际引用的 PNG、JPG/JPEG、WebP、GIF 或 SVG 图片。

PDF、教材、课件、实验资料、参考资料、压缩包、草稿、备份、未引用图片、其他 Markdown 文件和信息安全竞赛内容均不会上传。

## 学习笔记说明

笔记内容由个人学习整理和 AI 辅助生成，使用时请结合课程资料自行核对。仓库不提供竞赛资料、软件工具或自动化脚本下载.
